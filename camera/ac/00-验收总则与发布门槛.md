# 验收总则与发布门槛

版本 V2.3.1 · 2026-10-26。本文件是验收入口的收拢索引；各表以所注出处为准，修改出处时须同步本文件。

## 1. 验收口径

- 未测量不得声称达标（出处：技术大纲 G2）。
- 静态扫描不能证明运行时隐私或快门可用，必须配合抓包、故障注入和真机操作（技术大纲 §1）。
- 未执行≠通过；效果图≠可运行功能；文档已提交≠软件已验收。
- 未确认项不伪装为已实现能力；演示数据必须明确标识，不用隐藏 Mock 替代真实能力（PRD §9）。
- Markdown 结构与链接检查不等于真机、数据库或商店验收（调整记录）。

## 2. 质量门禁 G1–G5（以技术大纲 §1 为准）

| 门禁 | 一句话 |
|---|---|
| G1 并发安全 | Swift 严格并发检查；相机会话独立执行上下文 |
| G2 性能 | 真机预算实测，未测量不得声称达标 |
| G3 引导稳定 | 时间可注入状态机；稳定场景微抖无反复切换 |
| G4 快门独立 | CameraCore 不依赖 AI、账号或额度 |
| G5 授权边界 | 拒绝云分析零分析帧上传，拒绝反馈附件零截图上传 |

## 3. 阶段出口（以 PRD §10 为准）

| 阶段 | 范围 | 出口标准 |
|---|---|---|
| M0 可行性 | 真人引导对照、端侧姿态 demo、成本与设备预算验证 | 保存效果有改善证据；记录样本量和不确定性；性能/成本可行才进入开发 |
| M1 本地闭环 | FS-01/03/04/05/07/08/09，3 Tab、设置、必要权限 | 飞行模式完成模板→引导→拍摄→选片→调色→导出；原片不变、低存储可恢复 |
| M2 云端与运营 | FS-02/06/10/11，授权、账号、额度、后台与购买闭环 | 重复/超时/取消/崩溃均完成对账；拒绝授权零图像上传；后台审批审计可追溯 |
| M3 发布验证 | 真机矩阵、100 人外测、无障碍、隐私删除与订单测试 | 指标达标且有报告；待决策项关闭；发布负责人签字 |

## 4. 指标线（以 PRD §11/§14 为准；埋点 M1 前冻结）

| 指标 | 目标 |
|---|---|
| 北极星：AI 辅助后≥保存 1 张的会话比例 | M2 ≥50% |
| 建议采纳率（6s 内跟随） | ≥60% |
| 云端分析成功率 | ≥90%（内测） |
| 建议等待 p95（含本地降级） | ≤3s |
| 首张导出时长（进相机→保存相册） | ≤90s |
| 引导稳定性（恒定场景±2°微抖 60s 重复激活） | 0 次 |
| 崩溃会话率 | <0.1% |
