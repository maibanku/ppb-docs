1. 阅读[验收总则与发布门槛](./00-验收总则与发布门槛.md)，确认验收口径、G1–G5 门禁、阶段出口与指标线。

3. 用[验收执行记录模板](./验收执行记录模板.md)保存每次版本实测结果，原模板保留。
