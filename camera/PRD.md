## 1. 产品是什么

**一句话**：会指导你拍照的 AI 摄影师——选好想拍的样子，App 用箭头和轮廓指导你调机位、摆姿势，拍完帮你挑片、调色、存相册。

**核心链路**：

```
打开App(直接取景器) → 选目的(3选1) → 选模板(≤6张) → 「AI 指导」(≤3s出建议)
→ 箭头调机位(端侧实时) → 轮廓摆姿势(分步打勾) → 快门(单拍/3秒/连拍)
→ 选片(闭眼模糊自动标) → 调色(6风格) → 存相册
```

**北极星**：AI 辅助拍摄后至少保存一张照片的会话比例（M2 内测目标 ≥50%）。

**用户与解药**：被拍者（不知手放哪）→ 姿势轮廓分步引导；帮拍者（不知站哪/举多高/何时按）→ 机位箭头 + 达标触觉。

---

### 1.1 首版边界

P0：本地拍摄闭环、端侧指导、主动触发云分析、账号与额度、基础运营后台。P1：参考图导拍、语音播报、云同步、偏好记忆；P2：语音对话等探索。首版无社交动态、公开作品流、滤镜商店或自动上传。

### 1.2 产品原则 P1–P6

- **P1 一次一个动作**：同屏仅一条主建议，可忽略。
- **P2 少而精**：黑白灰、绿色点缀；默认收起模板扩展区，不展示未上线入口。
- **P3 不确定就静默**：低置信不强判姿势，不用错误指令换取覆盖率。
- **P4 随时可拍**：AI 不阻塞快门；相机权限、中断、存储失败仍须如实提示。
- **P5 本地优先**：本地功能免登录；登录、云分析授权和未来云同步独立。
- **P6 原片与编辑分离**：每张照片独立配方，导出不覆盖原片；本地存储不等于备份。

## 3. 功能明细（11 个 P0，每个 = 操作流 + 规则数值 + 异常兜底 + 联动埋点）

### FS-01 拍摄入口与模板选择

**操作流**：
1. 打开 App → 直接取景器（无开屏页），上次目的/模板自动恢复
2. 首次启动：系统相机权限弹窗 → 同意则出画 + 一次性提示「先选要拍什么」（3s 淡出）；拒绝则进权限引导页
3. 点右上角拍摄调整图标，再进入模板选择，在展开层选「穿搭全身」 → 绿描边 + `tick`，模板条 ≤1s 刷出 ≤6 张（图+名+难度★）
4. 点模板卡 → 半屏详情：4:5 大图、场景标签、难度、姿势分步预览、[♡收藏][就用这个]
5. 点「就用这个」→ 详情收起，取景器出现白色虚线姿势轮廓
6. 被拍者入镜 → 轮廓对齐 → 自动进入姿势引导；随时可直接按快门

**规则**：冷启到可拍 ≤1.2s（iPhone 12）；全部可跳过直接拍；记住上次选择（本地）；无网用 3 张内置兜底模板（标「离线模板」）；模板后台下发 + LRU 缓存 30 天。
**异常**：权限拒绝→引导页不死路；相机占用→「相机暂时不可用」+[重试]；模板加载失败→骨架占位可重试。
**联动埋点**：camera_open / purpose_selected / template_selected / template_favorited。

### FS-02 AI 现场分析

**操作流**：
1. 点「AI 指导」（快门右侧）→ 首次弹上传授权卡（每次主动分析仅传一帧/只用于建议/保留期发布前验证，目标最长24小时/免费额度以服务端为准）→ [同意并继续]
2. 建议条「正在看现场…」转圈；>1.5s 换「快了，再看一下构图…」；加载期间快门可拍，授权提示不覆盖拍摄操作区
3. 有效云结果确认后建议滑入（端到端p95目标≤3s，含本地降级） + `light`：「手机放低一点，让脚靠近下面的参考线。」→ 自动转机位引导
4. 点建议条可展开「为什么」一句话解释

**规则**：上传=单帧 JPEG（长边≤1280、q0.7）+目的/模板 ID+手机俯仰角，无定位；客户端自点击起 3s 截止；超时/无网/5xx → 端侧建议+「本地建议」角标，未确认任务不扣额度；额度尽 → 额度卡 [获取更多][继续普通拍摄]；分析中按钮禁用防重；离开取景器取消任务并丢弃迟到结果；取消与扣费规则见技术大纲 §7。
**异常**：抓帧全黑/明显无效→不上传，直接使用本地建议；弱网双发→requestId 幂等只扣一次；建议命中术语黑名单→落屏前替换端侧文案。
**联动埋点**：analysis_requested / analysis_succeeded / analysis_degraded / upload_consent_granted / upload_consent_declined。

### FS-03 机位引导 ★

**操作流**：
1. 建议出现（候选连续满足 1.5s 后）→ 箭头动画+参考线出现+`light`
2. 用户移动手机 → 箭头方向/幅度实时跟随（HUD 60fps 渲染）
3. 指标进入滞回带 → 箭头减淡（接近确认，不撤建议）
4. 达标 → 引导收起 + 参考线闪绿 + 「构图好了」toast 1.2s + `success` → 按优先级出下一问题，或接姿势引导
5. 6s 未达成 → 文案升级「还要再低一点，让脚碰到下面的线。」

**判定规则表（滞回方向随指标定义，禁止统一按小于判断）**：

| 问题 | 触发 | 解除 | 文案示例 |
|---|---|---|---|
| 无主体 | 2s 检测不到人 | 检出人 | 让被拍的人站进框里。 |
| 出框 | 外接框越取景边缘（余量<2%） | 全入框且余量>4% | 向左移动半步，避开画面边缘。 |
| 过小 | 人物高 <12% 屏高 | >20% | 再走近一步，让人物更占画面。 |
| 过大 | 高 >92% | <85% | 退后一点，人物快顶着边了。 |
| 头顶裁切 | 头顶留白 <1% 框高 | >4% | 上面留一点空，不要裁到头顶。 |
| 倾斜 | 倾角>4° | <2.5° | 把手机端平，参考线会对齐地平线。 |
| 逆光 | 人脸亮度/背景<0.35 | >0.45 | 让人侧一点身，别背对着窗。 |

**参数**：优先级（同屏 1 条）无主体>出框>大小>倾斜>头顶>逆光>姿势；解除驻留1.0s，同类冷却 2s；检测 15fps/单帧≤16ms（A12+）；建议上屏 ≤100ms；过热降级链：关轮廓→10fps→仅参考线。
**验收**：手持微抖 ±2° 下 60s 无重复激活抖动（恒定场景、噪声不跨真实问题边界；正常解除与升级另计）；全离线功能等价。
**埋点**：guidance_shown / guidance_followed（建议激活后6s内完成解除驻留=跟随）。

### FS-04 姿势引导

**操作流**：
1. 模板选定、人入镜 → 白轮廓贴合真人 + 第 1 步指令大字（如「左手轻轻搭在包带上」），对应关节呼吸闪烁
2. 被拍者摆到位（驻留 1s）→ 该步打勾 + `light` → 轮廓过渡到第 2 步
3. 偏差 → 「左手再抬高一点」+ 闪烁加速
4. 全部完成 → 「姿势到位，可以拍了。」+ `success` + 轮廓变绿 1.5s 淡出 → 快门圈微呼吸

**规则**：库 50 条×每条 2–3 步，指令 ≤12 汉字；端侧判定离线可用；左右自动镜像；置信度 <0.6 关节不判；弱光/侧身 45° 静默（宁可不说）；「换一个姿势」给同场景 3 个候选；多人入画只跟主体。
**异常**：检测丢失>2s → 「没看清姿势，请正对镜头。」；关节被遮挡 → 暂停该步判定，可跳过或换姿势，不能误判达标。
**埋点**：guidance_shown / pose_completed（姿势完成事件）。

### FS-05 拍摄与快门

**操作流**：
1. 模式条选「单拍/3秒/连拍」（`tick`）
2. 按快门 → heavy 触觉（全 App 唯一）+ 白闪 80ms → 原片最高质量 HEIC 存本地
3. ≤1.5s 左下缩略气泡弹出（带会话张数角标）
4. 点气泡 → 会话选片；3 秒模式按快门后 3→2→1（每秒 `light`，再点取消）；连拍 3 张，目标间隔 400ms，受设备处理能力约束

**规则**：快门响应 ≤50ms；AI 任何状态不禁用快门（G4 物理隔离）；变焦 0.5/1/2×、前后摄、闪光灯三态；存储 <200MB 提示。
**异常**：来电/切后台 → 无半张文件，回前台 ≤1s 恢复。
**埋点**：shot_taken。

### FS-06 灵感页

**操作流**：进 Tab → 缓存秒开（≤300ms）后台静默刷新 → 点分类过滤 → 点卡片看详情 → [♡收藏] 或 [去拍同款]（跳拍照页自动选中该模板）。
**规则**：卡片必标场景+难度；收藏全本地；下架模板收藏可见标「已下架」+ [看相似]；空分类「这个分类在准备了，先看看全部」。
**埋点**：template_favorited（来源=inspire）/ template_selected（来源=inspire）。

### FS-07 会话选片

**操作流**：
1. 点缩略气泡 → 本次会话网格（3 列，标题「本次拍摄 · N 张」）
2. 端侧标记 ≤2s 陆续上牌：闭眼/模糊角标、相似组折叠+★组内预选
3. 点照片全屏 → 左右滑对比，底部差异 chips（「没闭眼 · 背景更干净」）
4. 选 ≤3 张 → 「去调色 (N)」；[跳过] 则会话保留在作品页

**规则**：预选分=0.5清晰度+0.3无闭眼+0.2构图分；永不自动删除；全端侧离线；低光全糊给解释文案。
**异常**：30 张连拍聚类最多 3 组；第二张误入人脸不参与主体闭眼判定。
**埋点**：picker_opened / photo_selected。

### FS-08 调色与导出

**操作流**：
1. 进调色页 → 默认「自然」已应用
2. 点风格圆点（自然/清透/胶片/黑白/暖阳/冷调）→ 照片 ≤100ms 切换 + `tick`
3. 按住「按住看原片」→ 即时显示原片，松开回风格
4. 点「保存」→（首次申请相册 add-only 权限）→ `success` + 「已保存到相册」→ 回作品页

**规则**：6 风格内置 LUT，无滑杆无参数面板无商店；非破坏（原片字节不变，配方 recipe.json 可重置重放）；多张逐张独立配方；保留 EXIF。
**异常**：权限拒绝 → 引导卡 [去设置]，配方不丢；空间不足 → toast；连续快速点风格 → 合并渲染末次为准。
**埋点**：style_applied / export_completed。

### FS-09 作品页

**操作流**：进页 ≤300ms → 会话卡（缩略×4+张数+✓数+时间+目的）→ 点卡重入会话（已选置顶可重调色）→ 长按多选 → 删除二次确认「不会影响你保存到相册的成片」。
**规则**：统计行「本周拍了 N 次 · 保存 N 张」可关；首删展示一次「作品页是底稿」说明；空态引导 [去拍一张]；无推送无红点。
**埋点**：picker_opened（重入标记来源=gallery）。

### FS-10 设置、账号与额度

**操作流**：
1. 从拍照页调整面板进入设置 → 身份卡「游客 · 本地作品 N 组 · 免费 AI 分析 剩 N/10」
2. 点「我的额度」→ 详情：大数字+进度条+「每月 1 日（UTC）更新免费额度 · 未成功确认不扣次」+消耗记录（登录后）
3. 点「获取更多额度」→ 未登录则登录页（首句「照片仍在手机上」）→ 手机号+验证码 或 Apple 登录 → 成功 `success` 回额度页
4. 设置→账号管理→退出登录或删除账号；删除流程统一见 FS-10，不提供双模式

**规则**：登录只出现在三个触发点（充值/云同步P1/账号管理）；验证码 60s 重发、3 次错锁 60s；本地余额仅展示；IAP=额度包消耗型+会员订阅，购买待核验显示「购买结果确认中」，核验完成后刷新余额；退出后本地拍摄不受影响。
**埋点**：quota_viewed / purchase_started / login_started / login_succeeded。

### FS-11 合规四件套

**操作流**：
1. 首启拍照 → 系统相机权限 → 拒绝 → 自建引导页 [去设置][先逛逛灵感] → 设置开启后回前台自动恢复
2. 首次「AI 指导」→ 上传授权卡（FS-02）→ 拒绝后永不静默改判，可在隐私页重开
3. 首次保存 → 相册 add-only 权限
4. 反馈 → 类型（建议不准/闪退/其他）+文本 +截图勾选（默认不勾，勾了才上传）→ toast「收到，我们会看」

**规则**：V1 权限仅相机+相册 add-only，不申请定位/麦克风；隐私政策三处同源（登录页/关于/商店申报）；关闭云端分析后按钮变「本地指导」，不再上传；快门仍独立可用。
**埋点**：permission_* / upload_consent_* / feedback_opened / feedback_submitted。

## 4. 全局体验规则

1. **三条铁律**：每次只解决一个问题（优先级链见 FS-03）；建议稳定（恒定场景微抖60s无重复激活抖动）；AI状态不阻塞拍摄；相机中断或存储失败仍须提示。
2. **触觉 5 token**：`tick`切换 / `light`建议到达 / `success`达标导出 / `warn`降级 / `shutter`快门（唯一 heavy）。
3. **动效 5 token**：`fast`150ms / `standard`250ms / `guidance`200ms 文字淡切 / `celebrate`400ms / `shutterFlash`80ms。
4. **文案黑名单**（出现即验收不过）：曝光补偿、白平衡、ISO、感光度、景深、光圈、三分法、黄金分割、安全快门、动态范围、高光溢出、噪点、锐度、透视畸变、焦段、构图法则 → 一律译成动作。
5. **无障碍**：VoiceOver 焦点=视觉顺序、建议播报全文、达标播报「构图完成」；对比度≥4.5:1；高频操作全在屏幕下 1/3。

## 5. 数据与账号规则

| 数据 | 规则 |
|---|---|
| 原片/成片/配方 | 只存手机，永不默认上传 |
| 收藏/偏好/上次选择 | 本地 |
| 分析上传 | 单帧 JPEG+参数；任务终态即清理，最长保留 24 小时为待上线验证的服务承诺 |
| 余额/订单 | 服务端唯一事实源，本地只展示 |
| 运营统计 | 无照片内容、无位置 |

登录边界：端侧功能零登录；免费分析可不登录（授权后）；购买前必须登录；云同步必登录默认关。区分「删除账号/清本地数据/删相册照片」；说明**本地保存≠云备份**。

## 6. Web 管理后台需求（运营/客服/策略用，V1 必做）

后台用户四种角色：**超管 / 运营 / 客服 / 只读**。技术形态：Web（React）；后台独立身份体系，特权操作需二次验证。普通编辑可单人保存，发布/额度补偿需另一名有权限人员审批。

### 6.1 运营概览
- 仪表盘卡片：DAU、保存率（北极星）、建议采纳率、分析成功率、当日 AI 成本；时间筛选 7/30 天
- 无数据导出权限（防泄漏）；普通运营只看聚合，看不到个体照片

### 6.2 模板管理
- 列表页：筛选（目的/状态/难度）；字段：名称、目的、难度、场景标签、样片（3 尺寸）、绑定的姿势模板、素材授权记录（肖像权文件上传）
- 操作：新建/编辑/下架/恢复；**在线且前台运行的客户端 5 分钟内生效**（版本号轮询）；离线无法即时撤回，重连优先更新下架清单
- 姿势模板编辑：每步的关节约束与指令文案（过黑名单校验才可保存）

### 6.3 风格管理
- 6 个风格列表+预览样片；V1 风格随 App 版本发布，后台只记录版本与上下架状态；出问题撤回=发 App 补丁版本（后台标记）

### 6.4 AI 策略管理
- 提示词版本列表 + **diff 视图**；状态流转：草稿→灰度(5%→25%→100%)→稳定→废弃，可一键回滚
- 每版本关联黄金集回归报告（分数+两名摄影师盲评结果）；「新版本盲评分≥线上」是灰度的准入按钮条件
- 场景参数可配（如逆光阈值 0.35、滞回带宽）；**改动需双人复核**（第二人确认才生效）

### 6.5 用户与会员
- 搜索：手机号（受限权限）/匿名主体 ID；详情：注册时间、额度余额、订单列表、分析次数
- 操作：额度补偿（填原因，由另一位超管审批，全程留痕）；不得查看拍摄原片或分析帧；反馈截图仅授权的客服按工单访问。

### 6.6 反馈与评估
- 反馈列表：类型/状态（待处理→处理中→已解决）/用户勾选授权的截图预览
- 采纳率报表按策略版本分组（哪个版本的建议被跟随多）

### 6.7 成本监控
- 每日调用数/成本曲线；按策略版本的成本对比；日预算告警（超阈值邮件创始人）；单位成本=成本/成功分析次数

### 6.8 权限与审计
- 角色权限矩阵（只读/客服/运营/超管）；操作日志禁止后台用户修改或删除（谁、何时、改了什么、审批人）；保留期限与归档策略发布前确定

## 7. 服务端功能需求（唯一结算规则）

| 能力 | 产品规则 |
|---|---|
| 匿名身份 | 服务端签发匿名 token，不能凭客户端自填设备号取余额；匿名免费额度不保证跨设备恢复 |
| 账号 | 手机验证码与 Apple 登录；登录不迁移或上传本地作品，也不代表同意云分析 |
| 免费额度 | 按 UTC 自然月发放独立额度桶，过期不结转；游客绑定账号时每期仅一次合并，不能叠加领取 |
| 分析任务 | 创建时原子预留额度；有效结果经客户端校验并确认后才核销；未核销的失败、取消、确认超时任务释放 |
| 幂等 | `(subjectId, requestId)` 唯一，同键不同内容拒绝；同任务最多核销或释放一次 |
| 弱网对账 | 不把本地取消当作服务端取消；查询任务终态后刷新额度。确认回执丢失时查询，禁止新建任务重扣 |
| 模板 | 版本化增量、下架墓碑、资源校验；仅在线前台客户端承诺 5 分钟内刷新 |
| 数据清理 | 终态删除分析帧；后台清扫与删除告警保证最长 24 小时目标；不把对象存储生命周期当作准点删除保证 |
| 风控 | 匿名凭据、服务端频控和异常行为限流；不采集侵入式设备指纹，不使用“每天超过 3 次即异常”规则 |

任务状态、接口、并发结算和补偿验收见技术大纲 §7–9。

## 9. 发布准备

TestFlight 内外测→性能与失败路径验收→素材与隐私清单复核→提交审核→逐步放量。商店规则、分级、备案、账号删除和第三方处理方条款由负责人在发布前按目标地区核查，本设计不是已完成合规的证明。审核路径与实际用户一致；演示数据必须明确标识，不用隐藏 Mock 替代真实能力。

## 10. 开发顺序与阶段出口

以下按依赖顺序执行，工期由实际团队估算，不把原 8–10 人、28 周假设当成承诺。P0 是首版发布范围，并不意味着 M1 全部完成。

## 13. 风险与对策

WoZ 验证失败→M0 止损重设计；单帧测距不准→只说方向不说数值；建议抖动→防抖参数+验收线；AI 成本失控→端侧兜底≥40% 会话+成本红线；弱光姿态不准→静默降级+黄金集弱光覆盖；名字未定→M1 末截止；样片授权→后台授权链+法务 M1 评审。

## 14. 埋点口径补充与发布待决策

拍摄会话从进入取景开始；切到选片/调色仍属本会话，离开拍摄流程后台超过5分钟或用户明确新建时结束。作品页再次导出沿用原拍摄session_id并记录export_source。北极星分母为观察期内至少出现一条指导（本地或云）的拍摄会话，分子为其中至少成功导出一张到系统相册的会话；分端侧/云端报告。原片写入本地不算导出。shot_taken在成功写入原片后逐张上报；export_completed仅在系统保存成功后上报，按photo_id和export_id去重。

analysis_requested仅在真正创建云任务时记录；授权卡曝光不算请求。analysis_succeeded代表已确认云结果，analysis_degraded记录本地兜底；另记analysis_ready、analysis_ack_unknown、analysis_released用于排障。公共字段增加subject匿名标识、request_id/task_id、guidance_id、prompt_version与result_source，禁止携带照片、token或手机号。事件名保持完整，不用succeeded等缩写作为真实事件名。

发布前确认：云处理方及删除能力、反馈保留期、账号删除期限、付费价格与有效期、最低设备与性能基线、目标市场发布要求。未确认项不伪装为已实现能力。
