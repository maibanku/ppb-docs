# AI 相机 · 界面设计规范

> 2026-11-02 对齐说明：默认全屏无大参考框/遮罩、完整原片保存、ROI 选区与半圆变焦布局以 [FS-12](../pr/FS-12-AI选区与拍摄调整.md) / [FS-13](../pr/FS-13-半圆变焦控制.md) 为准；旧 3:4 默认参考框/遮罩只作历史布局。AI 后续能力见 [FS-14](../pr/FS-14-AI构图分析与实时引导.md)。

> V2.4 · 2026-11-01（Doka 参考边界收窄 + 四 Tab）。本规范仍是界面布局与视觉的唯一权威。

## 1. 设计方向

相机页采用全屏沉浸式取景器、顶部滑杆图标、悬浮控件、大尺寸白色快门和底部胶囊导航（**沿用现有沉浸式视觉方向**）。照片是主要视觉内容，控件不堆叠成参数面板。借鉴空间层级，保留本产品名称、图标、模板资产和业务结构。

**Doka 参考边界（V2.4 收窄，ADR-1101）**：仅参考 Doka 的「AI 构图交互功能」——即用户表达拍摄意图、取景器内给出构图辅助与引导对齐这一交互能力与信息层级。**不参考其布局、导航结构、配色、控件样式与图标资产**；不据此新增视频、自动构图、胶片商城等未经确认功能。

底部胶囊为四 Tab 固定：「拍照 / 灵感 / 作品 / 我的」，默认拍照；「我的」承载账号与设置（FS-10），相机页右上角调整面板保留设置快捷入口。取景器内构图辅助（3:4 参考框、九宫格、参考框中心点）均为纯预览叠加，不写入原片；中心点不是对焦点也不是识别结果（区分见[AI 构图交互与模块架构 §5](AI构图交互与模块架构.md)）。

## 2. 拍照页布局

取景画面延伸至屏幕四边，状态栏、闪光、右上角滑杆调整图标、变焦、最近照片、快门、构图指导及底部四 Tab 均悬浮在画面上。控件使用半透明深色衬底并适应安全区；参考线清晰标示实际 3:4 导出范围，超出范围可弱化显示。

- 右上角滑杆图标打开拍摄调整面板，面板中提供“选择拍摄目的与模板”、“构图辅助开关（中心点/九宫格，切换后画面内真实提示）”和“设置”明确入口；选中模板后在面板中显示名称，不常驻顶部。调整中心点或网格开关后出现真实 toast（如“中心点已开”），提示实际生效状态，不做无效果的装饰动画。构图指导入口（快门右侧）在未接入分析能力时明确标注“本地指导”，不得显示假进度或假达标（V2.4）。

| 项 | 规范 |
|---|---|
| 相机底色 | #000000；面板#1C1C1E；文字#FFFFFF/次级#B8B8BD |
| 强调色 | 绿色用于选中与引导达标；不可仅靠颜色区分状态 |
| 水平边距 | 16pt，空间不足时12pt |
| 取景器圆角 | 24–28pt，按屏幕尺寸调整 |
| 调整入口 | 滑杆图标，点击区域≥44×44pt，VoiceOver 标签“拍摄调整” |
| 工具点击区 | ≥44×44pt，视觉图标22–26pt |
| 快门 | 76–84pt白色双圈，留足可点击间距 |
| 底部胶囊 | 高52–56pt，置于底部安全区上方 |
| 文本 | 正文15–17pt；主建议17–20pt；支持动态字号 |

这些是适配目标，不从截图像素直接换算pt。以最小支持机型和大字号验证：优先保留快门、取景、AI入口；收紧垂直间距，将次级工具收入“更多”，不固定“取景器≥55%屏高”。横向不重叠，导航不遮挡系统手势区。

## 4. 展开层与状态

模板选择用半屏/全屏自适应sheet；关闭保留选择。云授权、额度提示用相机内非模态卡，不覆盖底部拍摄操作区；需要详细阅读时可进入详情并明确返回相机。普通系统权限弹窗遵循系统行为，不声称弹窗期间仍可点快门。

AI加载仅改变右侧按钮与建议条；快门不变灰。超时显示“本地建议”，不显示无限转圈。无权限时在原取景器位置放说明和“去设置”，仍能访问灵感与作品。过热仅展示简短状态，按技术大纲降级。

## 5. 其他页面与后台

灵感、作品、我的采用浅色底、大图片和克制分隔线；共享圆角、字号、绿色强调。作品无账号推销；我的与设置不展示P1灰色占位。Web后台用浅色画布、左导航、内容表格和明确状态；重点为模板、策略、任务/额度、反馈、审计，后台不照搬相机黑底。

## 6. 设计验收

- [ ] 一眼能找到拍摄调整入口、快门、构图指导和最近照片；不出现两个快门。
- [ ] 默认无常驻目的条/模板条/空建议条；主体画面优先。
- [ ] 中心点默认位于实际 3:4 参考框中心；开关后 toast 真实反馈；中心点/网格不进入原片、不冒充对焦或识别。
- [ ] 小屏、大字号、VoiceOver、减少动态效果下主流程可达。
- [ ] 3:4预览与导出裁切一致；前摄镜像下引导坐标正确。
- [ ] AI加载、授权拒绝、额度耗尽均能回到或继续本地拍摄；未接分析的指导明确标注“本地指导”，无假进度/假达标。
- [ ] 仅使用项目自身视觉资产，不将参考截图中的未知图标定义为新需求（Doka 仅参考 AI 构图交互功能，不参考布局/导航/配色/控件样式）。
