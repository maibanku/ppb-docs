## 1. 产品定位与全流程

**一句话**：会指导你拍照的 AI 摄影师——选好想拍的样子，App 用参考线、轮廓和建议指导你构图、摆姿势，拍完帮你挑片、调色、存相册。

**产品全流程（权威链路）**：

```
打开即拍（取景器直出）
  → 选目的（人像半身 / 穿搭全身 / 旅行打卡）与模板
  → 构图和姿势指导（本地辅助 → 端侧检测 → 真实云分析，三期递进）
  → 快门（单拍 / 3 秒倒计时 / 连拍；独立于 AI、账号、网络、额度）
  → 会话选片（模糊 / 闭眼 / 相似组仅建议，不自动删除）
  → 调色（6 风格非破坏配方，原片字节不变）
  → 导出（相册 add-only，导出副本与底稿分离）
```

- **打开即拍**是第一原则：AI 引导、上传授权、额度与网络等状态不得阻塞普通拍摄（PRD 原则 P4、门禁 G4）；相机权限未授予、系统中断、拍摄处理中、存储真实错误须如实禁用快门或给出失败提示，不得声称仍可拍。
- **北极星**与指标体系沿用 [PRD §11](PRD.md)，目标值不是已验证实测值。

## 2. 信息架构：四 Tab 固定

**Tab 顺序固定为「拍照 / 灵感 / 作品 / 我的」，默认落在拍照。**（ADR-1101，取代 V2.3 的三 Tab + 设置入口方案）

| Tab | 页面 | 内容 |
|---|---|---|
| 拍照（默认） | 取景器（深色沉浸式） | 全屏取景、3:4 参考框、构图辅助开关、快门、构图指导入口、右上角拍摄调整面板 |
| 灵感 | 模板库（浅色） | 分类 chips、双列瀑布流、模板详情、收藏、去拍同款（见 [FS-06](pr/FS-06-灵感页.md)） |
| 作品 | 作品库（浅色） | 统计行、会话卡、重入选片、删除底稿（见 [FS-09](pr/FS-09-作品页.md)） |
| 我的 | 账号与设置（浅色） | IAM 账号区、额度、权限、隐私、存储、反馈、关于（见 [FS-10](pr/FS-10-我的页与账号额度.md)） |

- 拍照页右上角**拍摄调整面板保留**：选择拍摄目的与模板、定位中心点与九宫格开关、进入设置（与「我的」Tab 的设置为同一内容的两个入口）。
- 未上线功能不展示灰色占位（原则 P2）；**未实现的入口不得伪装可用**（§12）。

## 3. 视觉方向与 Doka 参考边界

- **保留现有沉浸式视觉方向**：黑底全屏取景、悬浮控件、大快门、底部胶囊导航、黑白灰 + 绿色点缀（[界面设计规范 §1–2](tech/界面设计规范.md)）。
- **Doka 仅参考「AI 构图交互功能」**：即「用户表达拍什么 → 取景器内给出构图/姿势辅助 → 引导对齐 → 拍摄」这类交互能力与信息层级。
- **不参考 Doka 的**：布局、导航结构、配色、控件样式、图标、页面组织。本项目信息架构、视觉规范、控件尺寸全部以[界面设计规范](tech/界面设计规范.md)为准，不因参考截图引入新视觉元素或未经确认的功能（不做视频、滤镜商店、自动构图上传等）。

## 4. 拍照页功能与操作流

### 4.1 取景与本地构图辅助（第一期：纯本地，已定口径）

| 元素 | 规则 |
|---|---|
| 3:4 参考框 | 清晰标示实际导出范围，框外画面弱化显示；参考框几何为绘制与拍摄裁切的唯一事实源（详见[架构文档 §4](tech/AI构图交互与模块架构.md)） |
| 中心点 | **默认显示，位置固定在实际 3:4 参考框的几何中心**（非整屏中心）。纯预览开关：不是对焦点、不是主体识别结果、不参与任何检测判定、**不写入原片**。开关在调整面板与工具栏可达 |
| 九宫格 | 默认关闭的构图线开关，叠加在参考框内，纯 UI 覆盖，不写原片 |
| 真实反馈 | **调整中心点 / 网格开关后立即出现真实 toast**（如「中心点已开」），提示实际生效的开关状态；不出现无效果的花哨动画 |
| 诚实边界 | 中心点/网格只是静态辅助；**不显示假的对焦框动画、假的识别框、假的达标反馈** |

**中心点 ≠ 主体 ≠ 对焦** 的严格区分见[架构文档 §5](tech/AI构图交互与模块架构.md)：中心点是几何叠加；主体来自端侧检测；对焦属于设备控制，三者互不冒充。

### 4.2 构图按钮（AI 构图交互入口）

- 位置：快门右侧的「构图」按钮（沿用现有画面布局，不照搬 Doka 控件样式）。
- 点击后在**现有画面上显示轻量指导**（顶部轻量指导卡 / 建议条），内容分三期递进（§4.3）。
- **未接入分析能力时必须明确提示这是本地指导**：卡片如实标注「本地指导 · 未接入 AI 分析」，给出静态构图建议（如「让人物站进参考框、头顶留白」）。
- **禁止假进度、假达标**：不得显示伪造的加载进度、伪造的检测框、伪造的「构图已达标」；达标反馈只允许来自真实判定链路（端侧检测或云分析确认结果）。
- 指导卡可随时关闭；开关本身不消耗额度、不需要账号、不联网。

### 4.3 AI 构图交互三期递进（实现顺序，ADR-1101）

| 期 | 能力 | 触发与数据 | UI 表现 | 边界 |
|---|---|---|---|---|
| 第一期 · 本地辅助 | 参考框/网格/中心点 + 静态本地指导卡 | 纯本地，零采集 | 如实标注「本地指导」 | 不联网、不上传、不假达标 |
| 第二期 · 端侧检测 | 主体/姿态端侧检测 + 稳定引导状态机 | 设备本地推理，无网络 | 箭头/轮廓/参考线 + 分步姿势打勾；单条建议、滞回防抖（[FS-03](pr/FS-03-机位引导.md)/[FS-04](pr/FS-04-姿势引导.md)、技术大纲 §5） | 低置信静默（P3）；不阻塞快门 |
| 第三期 · 真实云分析 | 主动触发的单帧云分析 | 用户主动点击 + 单帧授权（§5） | 云建议一次一条，标注来源；失败降级本地 | 幂等 + 额度一致性（§5.3） |

三期是**实现顺序**也是**依赖顺序**：云建议落屏前仍需端侧重新校验现场与置信度（技术大纲 §5）。任何一期都不改变「打开即拍」。

### 4.4 目的与模板选择（[FS-01](pr/FS-01-拍摄入口与模板选择.md)）

**操作流**：打开 App 直接取景（上次目的/模板本地恢复）→ 点右上角调整图标 → 模板选择层 → 选目的（3 选 1，绿描边 + `tick`）→ 模板卡（≤6 张，图+名+难度★）→ 半屏详情（大图、场景标签、姿势分步预览、♡收藏 / 就用这个）→「就用这个」收起面板、取景器加载姿势轮廓目标。

- 可跳过目的与模板直接拍（P4）；无网用 3 张内置兜底模板（标「离线模板」）。
- 冷启到可拍目标 ≤1.2s（iPhone 12 基准，目标值非实测）。
- 灵感页「去拍同款」携带模板 ID 跳入拍照页并自动选中（[FS-06](pr/FS-06-灵感页.md)）。

### 4.5 快门与拍摄模式（[FS-05](pr/FS-05-拍摄与快门.md)）

- **快门独立**：快门路径不依赖 AI 状态、账号、网络、额度中的任何一项（门禁 G4）。无网、未登录、额度耗尽、分析中、分析失败，快门行为完全一致。
- 模式：单拍 / 3 秒倒计时（每秒 `light`，可取消）/ 连拍（3 张，目标间隔 400ms，受设备能力约束）。
- 快门按下：heavy 触觉（全 App 唯一）+ 白闪 80ms → 原片按参考框 WYSIWYG 裁切为 3:4 成片（裁切失败回退保存原图，不吞拍摄）→ 本地存储 → ≤1.5s 缩略气泡。
- 诚实边界：**未实现的模式/控件不显示**（无空按钮、无假变焦档位）。

### 4.6 自动曝光 / 变焦（预留设计，默认不做）

若后续实现任何自动曝光或自动变焦能力，必须同时满足：

1. **主动授权**：首次使用弹独立授权卡，说明将调整什么、何时调整；可拒绝且拒绝后不再弹。
2. **真实反馈**：调整发生时在画面内有真实指示（如「已调亮」），未调整不得显示。
3. **恢复入口**：提供一键恢复自动调整前状态或恢复系统默认的入口。
4. **默认不自动拍摄**：任何自动曝光/变焦都不得触发快门；拍摄永远由用户完成。

在以上四点未全部落实前，不做自动曝光/变焦功能，也不展示相关入口。

## 5. AI 现场分析（云，[FS-02](pr/FS-02-AI现场分析.md)）

### 5.1 触发与授权

- **只有用户主动点击才触发**；无任何后台自动分析、无定时分析、无默认上传。
- 首次点击弹**单帧上传授权卡**：说明本次仅上传一帧（长边≤1280、q0.7、去 EXIF/定位）、仅用于生成建议、保留期限与免费额度口径。[同意并继续] 后才发任务。
- **无默认原片上传**：授权针对「单帧分析」，不等于同意上传相册或原片；拒绝后永不静默改判，可在隐私页重开。
- 关闭云分析后构图按钮仍可用（回到本地/端侧指导）。

### 5.2 结果呈现

- 端到端等待预算 3s（目标值）；加载期间快门可拍，授权卡不覆盖拍摄操作区。
- **结构化建议一次一条**：单条主建议 + 可展开「为什么」一句话；同屏不并列多条云建议。
- **低置信静默**：云结果置信度不足或命中术语黑名单时不落屏，降级端侧建议或保持静默，不用错误指令换覆盖率（P3）。
- 有效云结果经客户端校验并确认（ack）后才展示并计费口径成立。

### 5.3 失败、超时、取消与额度一致性（技术大纲 §7/§9 为准）

- 超时 / 无网 / 5xx → 端侧建议 +「本地建议」角标；**未确认任务不扣额度**。
- 弱网双发 → `(subjectId, requestId)` 幂等，同任务最多扣一次。
- 离开取景器取消任务并丢弃迟到结果；本地取消不当作服务端取消，终态以查询为准。
- 额度尽 → 额度卡 [获取更多] [继续普通拍摄]；继续普通拍摄路径完整可用。

## 6. 会话选片（[FS-07](pr/FS-07-会话选片.md)）

- 点缩略气泡 → 会话网格（3 列）→ 端侧标记陆续上牌：**闭眼/模糊角标、相似组折叠 + 组内预选，全部只是建议，永不自动删除**。
- 全屏对比 + 差异 chips；选 ≤3 张去调色；[跳过] 会话保留在作品页。
- 预选分 = 0.5 清晰度 + 0.3 无闭眼 + 0.2 构图分；全端侧离线完成。

## 7. 调色与导出（[FS-08](pr/FS-08-调色与导出.md)）

- 6 风格（自然/清透/胶片/黑白/暖阳/冷调）内置 LUT，无滑杆、无参数面板、无商店。
- **非破坏**：原片字节不变，每张独立配方（recipe）可重置重放；「按住看原片」即时对比。
- 导出：首次申请相册 **add-only** 权限（只添加，不读取全部图库、不删除）；保存成功 toast + `success`；导出副本与底稿的关系见 §8。

## 8. 作品页与数据边界（[FS-09](pr/FS-09-作品页.md)）

- 会话卡（缩略×4 + 张数 + ✓数 + 时间 + 目的）；点卡重入选片可重调色。
- **删除底稿 ≠ 删除导出副本**：作品页删除只删本机底稿（tombstone + 后台清理），二次确认文案明确「不会影响你保存到相册的成片」；反之导出到相册的副本不受 App 内删除影响。
- 卸载可能丢失底稿；界面明确**本地保存 ≠ 云备份**（首版无云同步）。

## 9. 灵感页（[FS-06](pr/FS-06-灵感页.md)）

- 进页缓存秒开（目标 ≤300ms）+ 后台静默刷新；分类 chips 过滤；点卡看详情（与拍照页模板详情共用组件）。
- **收藏全本地**；**已下架模板**：收藏页保留卡片但标「已下架」+ [看相似]，不可拍同款；离线未收到下架墓碑时可用缓存，重连先同步下架清单。

## 10. 我的页（[FS-10](pr/FS-10-我的页与账号额度.md)，四 Tab 之一）

内容分区（浅色列表）：

| 分区 | 内容 |
|---|---|
| IAM 账号区 | 游客身份卡 / 登录（手机验证码或 Apple / 经 IAM 体系）；「照片仍在手机上」 |
| 我的额度 | 大数字 + 进度条 + 更新口径（每月 1 日 UTC）+「未成功确认不扣次」+ 消耗记录（登录后）；[获取更多额度] → 登录 → IAP（待核验状态如实展示） |
| 权限与隐私 | 相机 / 相册 add-only 权限状态与重开入口；云分析用途授权开关（关后构图按钮变本地指导） |
| 存储 | 本机底稿占用、清理入口、卸载丢失警示 |
| 帮助与反馈 | 反馈类型 + 文本 + 截图（默认不勾，勾选才上传且独立授权） |
| 关于 | 版本、隐私政策、协议 |

- 登录边界不变：端侧功能零登录；免费分析可不登录（授权后）；购买前必须登录；登录不迁移、不上传本地作品（PRD §5）。
- 退出登录 / 删除账号流程见 FS-10 §4；额度结算与购买一致性契约见技术大纲 §9。

## 11. Web 管理后台（camera-manager-web，挂 base-manage-web 底座）

范围与角色沿用 [PRD §6](PRD.md)。本期重点模块：

| 模块 | 要点 |
|---|---|
| 模板管理 | 新建/编辑/**发布审核**（双人：编辑保存草稿、另一权限人复核发布）/下架/恢复；在线前台客户端 5 分钟内生效；姿势文案过黑名单校验 |
| AI 策略 | 提示词版本 + diff、灰度与回滚、场景参数（阈值/滞回）双人复核 |
| 用户与额度 | 搜索（受限）、余额/订单/分析次数、**额度补偿审批**（另一超管审批留痕） |
| 客服反馈 | 工单状态流转、仅授权截图可见 |
| 审计 | 操作日志不可改删（谁、何时、改了什么、审批人） |
| 成本 | 调用数/成本曲线、策略版本成本对比、日预算告警 |

后台独立身份体系；不得查看拍摄原片或分析帧。

## 12. 诚实性总则（验收红线）

1. **未实现入口不伪装可用**：不显示无功能的按钮、开关、进度、达标反馈。
2. **未接分析明确本地提示**：构图指导未接端侧/云分析时，明示「本地指导」。
3. **不得假进度 / 假达标**：加载与达标反馈只能来自真实链路。
4. **目标指标不是实测值**：所有性能/成功率数字为验收目标，未测量不得声称达标。
5. 演示数据必须明确标识；不用隐藏 Mock 替代真实能力（PRD §9）。
