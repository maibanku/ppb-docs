## 4. 未实现（有明确证据的缺口）

- 云分析全链路：客户端（SceneIntelligence/PrivacyKit/EntitlementKit marker）与服务端 RPC（CAM-0001）均未实现；**未接任何真实云 AI，无端到端分析能力**。
- 端侧主体/姿态检测与引导状态机（PoseKit/GuidanceEngine marker）；取景器内当前只有**静态本地指导**。
- 模板网络下发客户端（NetworkKit marker；服务端 ListTemplates 已就绪但**端到端未接通**）。
- 拍摄模式：倒计时、连拍（CaptureView 明示不显示未实现控件）。
- 会话选片质量标记、6 风格调色内核与调色页（Editor 目录存在，深度未核验，未见 StyleKit 实现）。
- IAP、额度结算、登录绑定服务端。
- 管理后台真实 API 接入与模板发布审核流。
- 自动曝光/变焦：无任何实现（按 ADR-1101 预留，默认不排）。
