# FS-07 会话选片

> V2.3 · 2026-10-25；全局范围见[需求大纲](../PRD.md)，任务与额度契约见[技术大纲](../tech/技术大纲.md)。

| 元信息 | 值 |
|---|---|
| 优先级 | P0 |
| 所属页面 | 拍照页缩略气泡 → 会话选片页（深色） |
| 对应需求 | F-07（选片辅助）/ W-01（结果查看） |
| 依赖模块 | GalleryKit（闭眼/模糊/相似聚类，端侧）· StorageKit |
| 关联细则 | FS-05（拍摄产出口）· FS-08（选中后进入调色）· FS-09（作品页重入同一页面） |

## 1. 功能描述

拍完 10 秒内挑出可用的：本次会话所有照片进网格，系统**端侧**自动标记闭眼/模糊，相似照片折叠成组并预选组内最佳一张；每张给出一句差异说明。用户点选「去调色」，决定权永远在用户（不做自动删除，P1 原则）。

## 2. 入口与触发

| 入口 | 触发 | 现场 |
|---|---|---|
| 拍摄后缩略气泡 | 点左侧最近照片 | 进入**本次**会话 |
| 作品页会话卡 | 点任意会话 | 同一页面，可重选（重选不丢已调色历史，可重调） |

## 5. 状态矩阵

| 状态 | 触发 | 表现 |
|---|---|---|
| 标记中 | 刚拍完 | 未标记照片先正常展示，标记完成后角标浮现 |
| 全部模糊 | 低光会话 | 提示「这组光线偏暗，张张都偏软，选相对清晰的即可」 |
| 单张会话 | 只拍 1 张 | 无相似组，直接全屏视图 |
| 无网 | 断网 | 功能完整（全端侧，设计承诺） |
| 重入 | 从作品页 | 已选状态保留；重新调色不影响已导出历史 |

## 6. 动效与触觉

选中 `light` + 绿框 `fast`；组展开 `standard`；全屏切换 `standard`。无成功触觉（选片是过程，不是完成）。

## 7. 文案清单

- 页标题「本次拍摄 · N 张」
- 角标：「闭眼」「模糊」「相似」；推荐：★
- 差异 chips：「没闭眼」「背景更干净」「更清晰」「人物更完整」
- 底部：「跳过」「去调色」/「去调色 (2)」
- 低光提示：「这组光线偏暗，选相对清晰的就行。」

## 8. 无障碍

照片播报「第 2 张，已标记模糊」；选中播报「已选择」；全屏切换播报张序；对比 chips 播报。

## 9. 对抗场景

- 同姿势 30 张连拍：聚类阈值自适应，最多折叠 3 组，避免全部折叠。
- 双人误入第二张：第二张人脸不参与闭眼判定主体，仍显示「主体无闭眼」。
- 全部相似无法区分：推荐张给「为什么是它」说明（「这张最清晰，背景最干净」）。

## 10. 验收标准

- [ ] 进入到可点选 ≤500ms；标记全部完成 ≤2s（30 张内）
- [ ] 相似聚类准确率（内部黄金集）≥90%；预选张 = 用户最终选择的比例 ≥60%（M2 后用埋点验证）
- [ ] 差异说明与事实一致（人工抽检 20 组零错误）
- [ ] 无自动删除；跳过后会话完整保留在作品页
- [ ] 断网功能等价

## 11. 技术要点

- 闭眼：Vision 面部关键点眼睑置信度 <阈值；模糊：拉普拉斯方差 <阈值；相似：缩略图感知哈希 + 汉明距离聚类（组内预选分 = 0.5×锐度 + 0.3×无闭眼 + 0.2×构图分）。
- 标记结果持久化到 `PhotoRecord`，重入不重算。
- 全部计算在后台 actor，主线程只收结果事件。

## 12. 可用性测试脚本

1. 30 张连拍会话：「挑 2 张去调色」——10 秒内完成（≥4/5）。
2. 追问「★ 是什么意思」——理解组内预选（≥4/5）。
3. 「找出刚才那张闭眼的」——标记可信度主观评价（≥4/5）。
