# FS-04 姿势引导

> V2.3 · 2026-10-25；全局范围见[需求大纲](../PRD.md)，任务与额度契约见[技术大纲](../tech/技术大纲.md)。

| 元信息 | 值 |
|---|---|
| 优先级 | P0 |
| 所属页面 | 拍照页取景器 HUD 层 |
| 对应需求 | F-05 |
| 依赖模块 | PoseKit · GuidanceEngine（姿势判定）· StorageKit（姿势库）· DesignSystem |
| 关联细则 | FS-01（模板携带姿势目标）· FS-03（机位引导先行）· FS-05（达标后快门引导） |

## 1. 功能描述

被拍者的解药：选中模板后，取景器叠加**白色姿势轮廓**并对齐到检测到的人物；底部给一步一句的动作指令（「左手搭在包带上」），被拍者照做，端侧关节角度判定逐步打勾；全部完成提示「姿势到位，可以拍了」。姿势库 V1 共 50 条（M0 由摄影教材调研产出筛选），每条 2–3 步分解。

## 2. 入口与触发

| 入口 | 触发 | 行为 |
|---|---|---|
| 选定模板（FS-01） | 取景器检测到单人主体 | 轮廓出现并对齐；指令从第 1 步开始 |
| 机位引导全部达标后（FS-03） | 构图 OK 且有激活模板 | 若姿势未开始则自动开始 |
| 无模板直接拍 | 不启动（无姿势目标） | 可从顶部模式胶囊展开模板条选择一个姿势类模板启动 |

## 4. 交互细则（动作 → 效果 → 联动 → 埋点）

| # | 用户动作/系统事件 | 界面效果 | 联动 | 埋点 |
|---|---|---|---|---|
| 1 | 检测到人物且轮廓可对齐 | 白色轮廓渐显并贴合人物（`standard`） | PoseKit 关节对齐 | — |
| 2 | 系统给出第 1 步指令 | 指令条大字显示；对应关节呼吸闪烁 | GuidanceEngine 激活姿势判定 | guidance_shown(姿势) |
| 3 | 被拍者摆出该步姿势，端侧判定达标（驻留 1s） | 该步打勾 + `light`；轮廓过渡到下一步（`celebrate` 小版本） | 步骤推进 | — |
| 4 | 姿势偏差（如手太低） | 指令升级：「左手再抬高一点」+ 该关节闪烁加速 | coaching | — |
| 5 | 全部步骤完成 | 「姿势到位，可以拍了」+ `success`；轮廓变品牌绿实线 1.5s 后淡出；快门圈微呼吸 | 通知快门状态 | pose_completed |
| 6 | 用户点步骤条任意已完成步 | 指令条切换到该步（可回看重摆） | — | — |
| 7 | 检测丢失 >2s | 轮廓淡出 + 「没看清姿势，请正对镜头」 | 低置信静默 | — |
| 8 | 用户点「换一个姿势」 | 弹出同场景姿势候选 3 个（半屏） | StorageKit 同标签姿势库 | — |

## 5. 状态矩阵

| 状态 | 触发 | 表现 |
|---|---|---|
| 待对齐 | 有人但未对齐模板 | 轮廓半透明跟随，指令「站到和轮廓重合的位置」 |
| 引导中 | 对齐成功 | 分步指令 + 关节闪烁 |
| 低置信 | 弱光/遮挡/侧身 45°+ | 轮廓虚化 + 静默（P3 宁可不说） |
| 多人 | 第二人入画 | 只追踪主体；「让另一个人先出画」低频提示（≤1 次/10s） |
| 完成 | 全步达标 | 成功态 + 快门引导 |
| 未选模板 | 无姿势目标 | 本功能整体不激活 |

## 6. 动效与触觉

轮廓出现 `standard`；步完成 `light` + 勾选 `fast`；全完成 `success` + 轮廓变绿 `celebrate`；关节闪烁 = 1.2s 周期呼吸（品牌绿 60%→100% 透明度）。

## 7. 文案清单

- 指令模板：「左手轻轻搭在包带上」「重心放到后脚」「下巴微收，看向镜头上方一点」——全部来自 M0 教材语料 + 用户原声，按「部位+动作+参照物」句式。
- 升级：「左手再抬高一点」「再侧身一点点」
- 完成：「姿势到位，可以拍了。」
- 丢失：「没看清姿势，请正对镜头。」
- 多人：「让另一个人先出画，一次拍一个人。」

## 8. 无障碍

指令到达播报全文；步骤进度播报「第 2 步，共 3 步」；轮廓动画不承载唯一信息（文字同步）；色盲安全：完成态除颜色外加实线/虚线区分。

## 9. 对抗场景

- 被拍者穿宽松衣物/全身黑：轮廓对比度不足 → 轮廓自动加 1px 深色描边。
- 坐姿模板 + 检测下半身被桌遮挡：被遮挡关节标记degraded，暂停判定，给出跳过或换姿势入口。
- 镜像自拍（前置）：轮廓自动镜像。
- 人体朝向与模板左右相反：允许镜像匹配（左右脚对调不报错）。
- 90° 侧身强要求模板：置信度不足时降级为「大概姿势」判定（宽阈值），不卡用户。

## 10. 验收标准

- [ ] 姿势库 50 条，每条 2–3 步，全部按场景+难度标注
- [ ] 判定端侧完成、离线可用；步判定延迟 ≤500ms（达标到打勾）
- [ ] 每步指令 ≤12 个汉字，零术语
- [ ] 完成全程被拍者无需口头指挥（5 人可用性测试 ≥4/5）
- [ ] 左右镜像自动匹配；低置信静默不误报
- [ ] 完成态正确引导至快门（FS-05）

## 11. 技术要点

- 姿势库数据结构：`PoseTemplate { id, 场景标签[], 难度, steps: [PoseStep], 镜像允许 }`，`PoseStep { 关节约束组, 阈值, 指令, 升级指令 }`；SwiftData 缓存 + 内置兜底 12 条。
- 判定收敛在 GuidanceEngine（纯函数），PoseKit 只供 SmoothedPose；置信度 <0.6 的关节不参与判定。
- 镜像匹配：模板与人体骨架做左右翻转相似度取高者。

## 12. 可用性测试脚本

1. 被拍者视角：全程不看手机能否完成 3 步姿势（≥4/5 完成）——指令靠喊话传递。
2. 帮拍者视角：能否理解当前步与进度（≥5/5）。
3. 「换一个姿势」路径 10s 内可达。

## 13. 低置信判定补充

遮挡或置信度不足时暂停该步计时，不降低达标标准；允许跳过或换姿势。视觉插值不能作为判定输入。姿势步骤完成记录pose_step_completed，全部完成记录pose_completed，不与机位guidance_followed混用。
