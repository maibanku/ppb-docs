# FS-02 AI 现场分析

> V2.3 · 2026-10-25 · P0；依赖 SceneIntelligence、PrivacyKit、EntitlementKit、CameraCore。
> [技术协议](../tech/技术大纲.md) §7–9 为任务、时限和结算唯一来源。

## 1. 功能描述

用户主动点快门右侧“AI 指导”，经独立上传授权后分析一帧，输出一条动作建议。端侧指导无需登录和上传；云分析可由具备匿名凭据的游客使用。登录不代表授权，不触发上传。

## 2. 入口与触发

取景器运行时可触发，不要求预选模板。unknown展示授权卡，declined/revoked直接走本地指导；再次开启云分析须由用户进入设置操作。黑帧无效时不上传。

## 3. 页面布局

参见[界面规范](../tech/界面设计规范.md)：AI按钮在快门右侧，加载状态仅作用于按钮和取景器内建议条。授权和额度卡不覆盖快门区域；系统权限弹窗不属于此保证。模板选择层关闭后再开始分析。

## 4. 交互细则

1. 点击→检查用途授权、现场与网络；确认发起云请求时才记录analysis_requested。
2. 创建requestId并预留一次额度；相同任务重传沿用该ID，不重新扣次。
3. 从点击起3s等待预算，包含抓帧/上传/推理/确认；到期转本地建议。
4. 有效结果进入ready；仍在当前取景会话、授权有效且未超时才发送ack，确认核销后显示并交给端侧重校验。
5. ack回执丢失显示“结果确认中”，查询任务与额度；不得虚报“失败未扣次”。
6. 离开取景器或撤销授权：取消等待、发送幂等cancel、丢弃迟到结果；已核销的任务不自动退回。

## 5. 状态矩阵

| 状态 | 行为 |
|---|---|
| 无网/未授权/黑帧 | 不上传，显示本地建议，不新扣额度 |
| 加载 | AI按钮防重复，快门可用 |
| ready | 校验后确认；未确认到期自动释放 |
| committed | 展示建议，允许本次记录重新查看，不重复扣次 |
| 429 quota_exhausted | 非模态额度卡与继续本地指导 |
| 401 | 刷新身份或回到匿名路径，不显示“额度不足” |
| 超时/失败/取消且未确认 | 本地建议，查询或等待释放；缓存标“更新中” |
| 确认结果未知 | 查询终态，余额不得自行加回 |

## 6. 动效与触觉

加载不遮挡取景；到达light，建议淡入；连续失败不重复震动。减少动态效果时停止旋转/呼吸动效，保留文字。

## 7. 文案

“正在看现场…”、“本地建议”、“结果确认中”、“云端次数用完了，仍可使用本地指导”。授权说明按FS-11；禁止在处理方留存未验证前上线确定性删除承诺。

## 8. 无障碍

播报加载一次、结果一次；AI按钮包含忙碌状态；提示卡焦点可离开且有明确关闭入口，不抢占快门操作。

## 9. 对抗场景

双击、重复网络包、服务进程崩溃、同键不同内容、ack/cancel竞争、撤销期间上传、账号切换、旧结果到达新会话，逐项验证。

## 10. 验收

- [ ] 授权拒绝零分析图像上传，离线完整拍摄。
- [ ] 同任务最多核销一次，未确认任务最终释放，余额不负。
- [ ] ack丢失可查询终态，不虚假退款或重复创建。
- [ ] 端到端建议p95≤3s，云成功与本地降级分开统计。
- [ ] 分析加载、额度不足时快门操作正常；迟到建议不覆盖新现场。

## 11. 技术要点

上传JPEG长边≤1280，去除EXIF/定位；匿名token鉴权，不能凭设备号。结果需校验schema、枚举、长度、置信度与禁用术语；不合格不确认。分析原图不写日志，清理规则见技术大纲§9.3。

## 12. 测试脚本

首次授权→云分析→拍摄；拒绝授权→本地指导→拍摄；断网/额度耗尽→继续拍；确认回执丢失→查询扣次；请求中离开→等待释放；每条核对服务端任务、预留及流水。
