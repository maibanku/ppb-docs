# FS-05 拍摄与快门

> V2.3 · 2026-10-25；全局范围见[需求大纲](../PRD.md)，任务与额度契约见[技术大纲](../tech/技术大纲.md)。

| 元信息 | 值 |
|---|---|
| 优先级 | P0 |
| 所属页面 | 拍照页底部操作区 |
| 对应需求 | F-06 |
| 依赖模块 | CameraCore（`capturePhoto()`，G4 物理隔离）· DesignSystem |
| 关联细则 | FS-07（拍完成片气泡→选片）· FS-03/04（引导态影响快门视觉但不影响可用性） |

## 1. 功能描述

三种拍摄模式：单拍 / 3 秒倒计时 / 连拍 3 张。快门与 AI 状态**物理隔离**——分析转圈、引导未达标、额度用完，快门都照常可拍（原则 P4、门禁 G4）。原片按系统最高质量保存本地。

## 2. 入口与触发

拍照页底部中央快门钮 76–84pt；模式切换位于独立工具栏，点开选择单拍/3秒/连拍；变焦 0.5×/1×/2×（设备支持时）横排在取景器下缘；前后摄切换位于工具栏。

## 3. 页面布局

```
│ (单拍 · 3秒 · 连拍)           │ ← 模式条 32pt，选中白底黑字
│                              │
│      [▣]   ( ● )   [AI指导]   │ ← 左最近照片、中央快门、右AI指导
│                              │
│  拍照🔴      灵感      作品    │
```

倒计时激活时快门钮内显示 3→2→1 大数字；连拍时快门内三点进度。

## 5. 状态矩阵

| 状态 | 触发 | 表现 |
|---|---|---|
| 可拍（默认） | 会话运行 | 白圈快门 |
| 引导中拍摄 | AI 引导激活 | 快门不变灰，照常 |
| 分析中拍摄 | FS-02 转圈 | 照常 |
| 不可拍（极少数） | 相机中断/权限吊销/无法写入存储 | 快门禁用态 + 顶部中断说明；恢复后自动回可拍 |
| 连拍中 | 3张序列处理中 | 禁止重复启动，直到序列完成或失败 |
| 倒计时取消 | 再次点击 | 数字消失回到待拍 |

## 6. 动效与触觉

快门按下 `shutter`（heavy 一次性）+ `shutterFlash`（80ms 白闪 60% + 圈收放 120ms）；倒计时每秒 `light`；拍摄完成气泡 `standard`。全 App 唯一 heavy 触觉就是快门。

## 7. 文案清单

- 模式：「单拍」「3秒」「连拍」
- 中断：「拍摄被来电打断了，回到拍照即可继续。」
- 恢复失败（极端）：「相机暂时不可用，重启 App 或检查权限。」

## 8. 无障碍

快门播报「快门」；倒计时播报「3、2、1」；模式切换播报选中模式；连拍完成播报「已拍 3 张」；快门支持 Switch Control / 全键盘激活。

## 9. 对抗场景

- 连拍三张全闭眼：交给 FS-07 标记，不在拍摄端处理。
- 倒计时中被拍者未就位：可再点取消，不限次数。
- 低电量 (<10%)：顶部条提示，不改交互；性能预算内完成拍摄（G2）。
- 存储空间不足：拍摄前检查，<200MB 时顶部提示「空间不足，请清理后再拍」。

## 10. 验收标准

- [ ] 快门延迟（按下到快门动画）≤50ms；任何 AI 状态不禁用快门（自动化验证 G4）
- [ ] 原片按系统最高质量 HEIC 保存；单张拍摄完成到缩略气泡 ≤1.5s
- [ ] 倒计时可随时取消；连拍目标3张、间隔400ms；硬件受限时降低频率并验证完整性
- [ ] 中断（来电/切后台）无半张损坏文件，恢复 ≤1s
- [ ] 快门触觉全 App 唯一 heavy，与系统相机手感对齐

## 11. 技术要点

- `capturePhoto()` 只走 AVCapturePhotoOutput，代码路径上不 import 任何 Guidance/Analysis 状态（CI 可断言依赖方向，G4 的结构性保证）。
- 倒计时使用单调时钟计算剩余时间；连拍按设备能力调度3次拍摄，目标间隔400ms，不假定存在一次请求完成的统一burst API。
- 文件写入：先写临时目录再原子移动到会话目录，杜绝半张文件。
- 快门圈动画参数与系统相机手感对齐（M0 与系统相机逐帧对比校准）。

## 12. 可用性测试脚本

1. 「帮我拍一张」→「再连拍三张」——模式切换与完成感知（≥5/5）。
2. 倒计时摆姿势——取消路径可发现（≥4/5）。
3. AI 转圈时按快门——用户无感知阻塞（不打断即为通过）。
