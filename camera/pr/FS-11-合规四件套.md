# FS-11 权限、上传授权、隐私说明与反馈

> V2.3 · 2026-10-25 · P0。本文规定产品行为与待验证事项，不表示已经通过商店或法律合规审核。

## 1. 功能描述

四项共用能力：系统权限、用途独立的上传授权、可达的隐私说明、反馈与可选附件。账号删除见FS-10。首版只申请相机和相册add-only；语音播报不需麦克风，语音输入另行设计。

## 2. 入口与触发

相机在首次进入取景时申请；相册在首次导出时申请。首次云分析展示分析授权；反馈截图每次提交单独勾选，默认关闭。设置→隐私与权限可撤销云授权。登录、授权、未来云同步是三种独立行为。

## 3. 页面布局

相机权限拒绝在取景区显示“去设置 / 先看灵感”。上传授权用不覆盖拍摄区的非模态卡，详细说明可打开独立页。说明每次主动分析只传一帧、用途、处理方、保留期与关闭入口；免费次数从配置读取。设置页只显示已实现权限，不出现P1麦克风占位。

## 4. 交互细则

unknown→granted/declined；granted→revoked；declined/revoked仅由用户主动在设置重新授权。授权按用途与政策版本保存，重大用途变更重新确认。撤销立即阻止新抓帧上传，取消在途任务；已送出的数据无法撤回网络传输，应触发服务端清理。云授权关闭后显示“本地指导”，不把AI按钮变成第二个快门。

## 5. 状态矩阵

| 状态 | 处理 |
|---|---|
| 相机拒绝 | 取景不可用，灵感/作品仍可访问 |
| 相册拒绝 | 导出失败提示，原片与配方保留 |
| 权限从设置恢复 | 回前台重新查询，无需重启 |
| 分析授权拒绝/撤销 | 零新增分析图像上传，本地指导继续 |
| 反馈附件未勾选 | 仅发送文本；不静默附截图或诊断图像 |
| 政策版本需重确认 | 暂停云上传，用户同意后恢复 |

## 6. 动效与触觉

权限说明克制，反馈提交确实成功后才success。系统弹窗由系统控制，不承诺该弹窗打开时仍可操作快门。

## 7. 文案与数据承诺

相机：“用于实时取景与拍摄照片。”相册：“仅用于把成片保存到相册。”分析卡：“每次主动分析会发送当前一帧用于生成建议；可随时在设置关闭。”保留期目标为终态清理、最长24小时；必须在处理方、对象存储、日志和备份验证后才能将确定期限写入正式授权文案。反馈截图的保留期、访问角色与删除方式在上线前明确，不套用分析帧期限。

## 8. 无障碍

授权内容可逐项阅读，同意/暂不同等可达；相机权限说明与返回路径有语义标签；屏幕阅读器不被非模态提示卡锁死。

## 9. 对抗场景

授权撤销与上传竞争、退出账号后匿名上传、分析被拒但主动提交反馈、SDK自动附件、政策版本升级、系统相册写入失败都需专项检查。审核路径与正式能力一致，演示数据明确标注，不用隐蔽Mock应付审核。

## 10. 验收

- [ ] 首版无定位/麦克风权限；系统权限按需申请。
- [ ] 未授权和撤销后零新增分析帧上传；反馈附件按独立勾选控制。
- [ ] 登录不改变上传授权，云同步未实现即无上传入口。
- [ ] 隐私政策、商店申报和实际网络行为一致；地区要求发布前核验。
- [ ] 删除任务可追踪，保留期有测试证据和超期告警。
- [ ] 所有拒绝路径保留本地数据及可用的返回路径。

## 11. 技术要点

PrivacyKit统一用途授权与版本；SystemPermissionCenter封装系统查询。AnalysisUpload和FeedbackUpload均经过独立守卫，不能仅扫描SceneIntelligence。服务端鉴权、任务归属与附件访问控制单独验证。图像不进入埋点、崩溃附件或普通日志。备案等发布资料单独维护，不假定存在系统专用Info.plist键。

## 12. 测试脚本

全新安装拒相机→设置恢复；拒云分析→本地拍→单独同意反馈截图；请求中撤销→抓包与清理记录；拒相册→恢复→重新导出；逐项对照用途、数据和文案。
