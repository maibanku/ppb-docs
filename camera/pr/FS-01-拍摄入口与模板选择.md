# FS-01 拍摄入口与模板选择

> V2.3 · 2026-10-25；全局范围见[需求大纲](../PRD.md)，任务与额度契约见[技术大纲](../tech/技术大纲.md)。

| 元信息 | 值 |
|---|---|
| 优先级 | P0 |
| 所属页面 | 拍照页（Tab 1，默认页，深色） |
| 对应需求 | F-01（目的选择）/ F-02（模板选择） |
| 依赖模块 | CameraCore · StorageKit（模板缓存）· DesignSystem |
| 关联细则 | FS-02（分析入口）· FS-03/04（引导承接模板）· FS-06（灵感页同款跳入） |

## 1. 功能描述

冷启动直接进入取景器。用户可点右上角拍摄调整图标，在展开层选择拍什么（人像半身/穿搭全身/旅行打卡），并浏览模板横滑条（≤6 张样片）；选中模板即确定「拍成什么样」——构图、姿势、色调目标随之加载。可跳过目的与模板直接拍（原则 P4）。

这一步是与「普通相机」的第一处分界：用户可以先表达拍摄意图，也可以不选模板直接拍。

## 2. 入口与触发

| 入口 | 触发 | 现场 |
|---|---|---|
| 冷启动 | 默认落地页 | 上次使用的目的与模板记忆恢复（本地） |
| 灵感页「去拍同款」 | 携带模板 ID 跳入 | 自动选中该模板并进入取景 |
| 从选片/作品返回 | 返回拍摄 | 保留本次会话与已选模板 |
| 首次启动 | 相机权限申请（见 FS-11） | 拒绝→权限引导页；同意→取景器加载 + 一次性 coach mark「先选要拍什么」3s 淡出 |

## 3. 页面布局

按[界面设计规范](../tech/界面设计规范.md)：全屏取景，右上角滑杆图标打开调整面板；左最近照片、中央快门、右AI指导及底部3 Tab悬浮于取景画面。设置通过调整面板进入。

目的与模板选择收进拍摄调整面板的模板选择层，不常驻取景器；默认不显示模板文字，已选名称在调整面板中展示。展开后提供目的3选1、≤6张模板、详情和收藏。建议为空时不占位。快门与Tab分离，拍照Tab不显示第二个快门。

## 4. 交互细则（动作 → 效果 → 联动 → 埋点）

| # | 用户动作 | 界面效果 | 联动 | 埋点 |
|---|---|---|---|---|
| 1 | 冷启动完成权限 | 取景器加载；coach mark 3s 淡出 | CameraCore.start() | camera_open |
| 2 | 在模式展开层点目的 | 选中态绿描边（`fast`）；模板条横向滚动 | 模板条按目的过滤刷新 ≤1s | purpose_selected |
| 3 | 点模板卡 | 半屏 sheet 滑入（`standard`）：样片大图 4:5 + 场景标签 + 难度★1-3 + 姿势分解预览 + [♡收藏][就用这个] | StorageKit 读模板详情 | — |
| 4 | 点「就用这个」 | 选择层收起；调整面板显示模板名；取景器出现该模板**姿势轮廓预览**（白色虚线人形，等用户入镜后对齐） | GuidanceEngine 加载 pose template；FS-04 就绪 | template_selected |
| 5 | 点「♡收藏」 | 心形填充 + `tick` | StorageKit.TemplateFavorite | template_favorited |
| 6 | 点「AI 指导」 | 按钮进入加载态（环形进度 + 文案「正在看现场…」） | →FS-02 流程 | analysis_requested |
| 7 | 快门/模式/缩略图 | 见 FS-05 / FS-07 | — | shot_taken |
| 8 | 不选目的直接拍 | 全部可用，无引导（P4） | GuidanceEngine 仅基础参考线 | —（同 camera_open） |

## 5. 状态矩阵

| 状态 | 触发条件 | 表现 |
|---|---|---|
| 正常 | 权限已授 | 取景器+右上角拍摄调整图标；模板条仅在展开层可见 |
| 权限拒绝 | 用户拒绝相机 | 自建引导卡：「拍照需要使用相机」+ [去设置]；不阻塞 Tab 切换 |
| 相机不可用 | 硬件占用/故障 | 全屏占位：「相机暂时不可用」+ [重试] |
| 模板缓存缺失 | 无网且首次 | 模板条显示 3 张内置兜底模板；标注「离线模板」 |
| 模板加载失败 | 有网但失败 | 占位骨架 + 点击重试；不影响拍照 |
| coach mark 已展示 | 二次启动 | 不再出现 |
| 目的未选 | 跳过 | 一切可拍；「AI 指导」仍可用（无目的通用分析） |

## 6. 动效与触觉

目的选中：`fast` + `tick`；sheet 滑入/收起：`standard`；姿势轮廓出现：`guidance` 渐显；coach mark：`standard` 淡入、3s 后 `standard` 淡出。

## 7. 文案清单（黑名单校验通过）

- 目的：「人像半身」「穿搭全身」「旅行打卡」
- coach mark：「先选要拍什么，再开始」（仅一次）
- sheet：模板名（如「咖啡店窗边坐姿」）、场景标签、「难度 ★2」、「姿势分 3 步，跟着轮廓来」、按钮「就用这个」「♡收藏」
- 拒绝权限：「拍照需要使用相机。可以在设置里重新打开。」按钮「去设置」「先用其他功能」

## 8. 无障碍

VoiceOver 焦点顺序：拍摄调整图标 → 取景器工具 → 当前建议 → 变焦 → 拍摄工具 → 最近照片 → 快门 → AI指导 → TabBar；展开层独立管理焦点。胶囊选中播报「人像半身，已选择」。快门提供 switch control 激活。

## 9. 对抗场景

- 用户从灵感页快速连点「去拍同款」两次：sheet 去重，只入栈一次。
- 收到下架墓碑后禁止新选模板，保留历史名称；离线尚未得知下架时可用缓存，重连先同步下架清单。
- 小屏：目的与模板选择在调整面板中显示；工具收纳与安全区遵循界面设计规范。

## 10. 验收标准

- [ ] 冷启动到可拍 ≤1.2s（iPhone 12 基准机）
- [ ] 选目的后模板条 ≤1s 刷新；模板详情 ≤300ms（缓存命中）
- [ ] 跳过目的与模板可完整拍照
- [ ] 灵感页「去拍同款」正确携带模板并自动选中
- [ ] 权限拒绝不是死路（引导页可达系统设置）
- [ ] coach mark 全生命周期只出现一次

## 11. 技术要点

- 目的与模板数据来自后台下发（`GET /v1/templates`），StorageKit LRU 缓存 30 天 + 3 张内置兜底模板保证离线可用。
- 「上次记忆恢复」只存本地 UserDefaults（目的 ID、模板 ID），不含任何用户内容。
- 模板详情 sheet 与灵感页详情共用同一组件（DesignSystem 复用），避免双实现。

## 12. 可用性测试脚本（5 人）

1. 「拍一张全身穿搭照」——观察是否先选目的再选模板（正确率 ≥4/5）。
2. 「不选模板直接拍一张」——验证跳过路径无阻断。
3. 从灵感页「去拍同款」进入——验证模板自动选中（正确率 5/5）。
