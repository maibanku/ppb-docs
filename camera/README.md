## 维护约定

产品原则P1–P6见PRD§1.2；质量门禁G1–G5见技术§1；埋点见PRD§11/14。V2.4 起产品功能与操作流以[产品功能设计](产品功能设计.md)为单一入口，范围与产品规则以PRD为准，界面布局以界面规范为准，任务/额度状态以技术§7–9为准；修改时同步受影响的FS与[追踪矩阵](ac/需求追踪矩阵.md)，不能依赖优先级掩盖矛盾。历史F/C/W等编号仅作旧文档追踪，新工作项统一使用FS编号与章节。四 Tab 固定为「拍照 / 灵感 / 作品 / 我的」，默认拍照（ADR-1101）。
