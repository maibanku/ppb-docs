# 管理端

> v0.2 草案；目标态，未实施。覆盖功能点 FP-G。规则编号的前缀与 [PRD](../PRD.md) 第 6 节的功能点编号一致。全部在 M4 交付，FP-G18 随 M2 一起完成。

[需求基线](../PRD.md) · [技术设计](../tech/07-管理端设计.md) · [域导航](../README.md)

## 0. 通用规则

| 编号 | 规则 |
|---|---|
| G00-1 | 管理端是一个独立的插件工程，接入平台管理门户，使用平台管理员的登录态 |
| G00-2 | 每个操作对应一个权限点，见 FP-G16。前端按权限显示按钮，服务端对每个请求复检 |
| G00-3 | 所有管理写操作都记审计，见 FP-G15 |
| G00-4 | 列表都支持搜索、筛选、排序、分页。每页默认 20 条，上限 100 条 |
| G00-5 | 管理端不展示任何成员邮件的内容，见 FP-G18 |

## 1. 域名、邮箱、别名、转发

### FP-G01 域名管理页（M4）

| 编号 | 规则 |
|---|---|
| G01-1 | 域名列表显示：域名、是否默认、状态、邮箱数量、DKIM 选择器、DNS 校验汇总、证书剩余天数 |
| G01-2 | 添加域后立即展示需要配置的 DNS 记录，并自动执行一次校验 |
| G01-3 | 域详情页包含：DNS 记录清单（可复制）、逐项校验结果和检测时间、DKIM 公钥 |
| G01-4 | 域详情页可操作：重新校验、轮换 DKIM 密钥、删除旧选择器 |
| G01-5 | 域可设为默认、停用、启用、删除。删除规则见 FP-D01 |
| G01-6 | 权限：`mail.domain.read` 查看，`mail.domain.manage` 管理 |

### FP-G02 邮箱总览页（M4）

| 编号 | 规则 |
|---|---|
| G02-1 | 列表列：邮箱地址、所属用户的名称和编码、域、状态、已用容量和配额、最近登录时间、外发权限 |
| G02-2 | 可按地址、用户名、用户编码搜索；可按域、状态、外发权限筛选；可按容量用量、地址、最近登录时间排序 |
| G02-3 | 页面顶部汇总：邮箱总数、各状态数量、总用量、配额总量 |
| G02-4 | 权限：`mail.account.read` |

### FP-G03 邮箱详情与单个操作（M4）

| 编号 | 规则 |
|---|---|
| G03-1 | 详情页显示：基本信息、容量用量、别名列表、转发设置、自动回复是否启用、过滤规则数量、最近登录记录 |
| G03-2 | 开通邮箱：选择用户和域，填账号名（默认带出用户编码），设置初始密码或由系统生成临时密码 |
| G03-3 | 可修改主地址、配额、外发权限 |
| G03-4 | 可重置密码，临时密码只显示一次 |
| G03-5 | 可停用、恢复、删除。待删除的邮箱可恢复，也可立即彻底删除 |
| G03-6 | 权限：`mail.account.read` 查看，`mail.account.manage` 操作 |

### FP-G04 批量操作（M4）

| 编号 | 规则 |
|---|---|
| G04-1 | 对筛选结果或勾选的邮箱，可批量：停用、恢复、设置配额、开启或关闭外发权限、删除 |
| G04-2 | 单次最多 500 个邮箱。返回成功数、失败数和失败明细 |
| G04-3 | 按组织批量开通：选择一个或多个组织，为其中还没有邮箱的成员开通邮箱 |
| G04-4 | 批量操作在后台执行，页面显示进度和结果 |
| G04-5 | 权限：`mail.account.manage` |

### FP-G05 别名管理（M4）

| 编号 | 规则 |
|---|---|
| G05-1 | 列出全部别名，可按别名地址和所属邮箱搜索 |
| G05-2 | 可添加和删除别名，页面显示每个别名属于哪个邮箱 |
| G05-3 | 权限：`mail.alias.read` 查看，`mail.alias.manage` 管理 |

### FP-G06 转发管理（M4）

| 编号 | 规则 |
|---|---|
| G06-1 | 列出全部转发设置：邮箱、转发地址、是否保留副本、是否已验证、来源是用户自助还是管理员设置 |
| G06-2 | 管理员可增、删、改转发设置，无须验证 |
| G06-3 | 权限：`mail.forward.read` 查看，`mail.forward.manage` 管理 |

## 2. 策略、队列、日志

### FP-G07 黑白名单管理（M4）

| 编号 | 规则 |
|---|---|
| G07-1 | 列表显示：类型（地址或域）、名单值、所属名单（黑名单或白名单）、添加人、添加时间、备注 |
| G07-2 | 可添加和删除。添加时校验格式；一次可粘贴多个值 |
| G07-3 | 白名单里的发件人入站时跳过垃圾评分，直接投递 |
| G07-4 | 黑名单规则见 FP-S08 |
| G07-5 | 权限：`mail.blocklist.read` 查看，`mail.blocklist.manage` 管理 |

### FP-G08 出站限额配置（M4）

| 编号 | 规则 |
|---|---|
| G08-1 | 全局默认值：每账号每小时收件人数上限、每天收件人数上限 |
| G08-2 | 可给单个账号设置覆盖值，以列表管理 |
| G08-3 | 权限：`mail.policy.read` 查看，`mail.policy.manage` 管理 |

### FP-G09 邮件队列管理（M4）

| 编号 | 规则 |
|---|---|
| G09-1 | 队列列表显示：队列标识、大小、到达时间、发件人、收件人、失败原因、已重试次数 |
| G09-2 | 可按发件人、收件人、队列标识搜索；可按队列类型筛选：等待投递、延迟重试、暂缓 |
| G09-3 | 可操作：立即重发全部、重发选中的、把选中的改为暂缓、释放暂缓的、删除选中的 |
| G09-4 | 删除需要二次确认。单次操作最多 1000 封 |
| G09-5 | 入站方向的邮件在队列里只能查看，不能删除 |
| G09-6 | 权限：`mail.queue.read` 查看，`mail.queue.manage` 操作 |

### FP-G10 投递日志（M4）

| 编号 | 规则 |
|---|---|
| G10-1 | 列表显示：时间、方向（收或发）、发件人、收件人、大小、投递状态、耗时、是否加密、认证账号、客户端地址、邮件追踪号、退信原因 |
| G10-2 | 筛选：时间范围（默认最近 24 小时）、方向、状态、发件人、收件人、追踪号 |
| G10-3 | 可把当前筛选结果导出为表格文件，上限 10 万行 |
| G10-4 | 记录保留 180 天 |
| G10-5 | 权限：`mail.log.read` |

### FP-G11 登录日志（M4）

| 编号 | 规则 |
|---|---|
| G11-1 | 列表显示：时间、邮箱地址、协议（IMAP、POP3、SMTP 提交）、客户端地址、结果（成功或失败）、失败原因 |
| G11-2 | 筛选：时间范围、协议、结果、邮箱地址、客户端地址 |
| G11-3 | 记录保留 180 天 |
| G11-4 | 权限：`mail.log.read` |

### FP-G12 垃圾评分记录（M4）

| 编号 | 规则 |
|---|---|
| G12-1 | 列表显示：时间、发件人、收件人、评分、处置结果（拒收、进垃圾邮件、灰名单、正常投递）、命中的主要规则 |
| G12-2 | 筛选：时间范围、处置结果、评分区间、发件人、收件人 |
| G12-3 | 可从一条记录直接把发件人或发件域加入黑名单或白名单 |
| G12-4 | 记录保留 30 天 |
| G12-5 | 权限：`mail.log.read` |

### FP-G13 系统状态（M4）

| 编号 | 规则 |
|---|---|
| G13-1 | 显示各组件是否正常：Postfix、Dovecot、Rspamd、Redis、数据库、控制面服务 |
| G13-2 | 显示队列长度，分等待投递、延迟重试、暂缓三类 |
| G13-3 | 显示邮件存储磁盘用量、数据库用量、证书剩余天数、DNS 校验汇总 |
| G13-4 | 每 30 秒自动刷新，也可手动刷新 |
| G13-5 | 异常项在页面显著提示 |
| G13-6 | 权限：`mail.status.read` |

### FP-G14 全局设置（M4）

| 编号 | 规则 |
|---|---|
| G14-1 | 可配置项：默认配额、单封大小上限、收件人上限、出站限额默认值、各项保留期、暂存附件的上限和保留时间、自动开通范围及其组织、用户自助转发开关、用户自助别名数量上限、可执行附件拦截开关、灰名单开关、垃圾评分阈值、POP3 开关 |
| G14-2 | 每项显示当前值、默认值和允许范围 |
| G14-3 | 修改后 1 分钟内生效；个别需要重启组件才能生效的项在页面上注明 |
| G14-4 | 权限：`mail.settings.read` 查看，`mail.settings.manage` 管理 |

### FP-G15 管理操作审计（M4）

| 编号 | 规则 |
|---|---|
| G15-1 | 记录内容：操作者、时间、客户端地址、动作、对象类型和标识、变更前后的值、结果 |
| G15-2 | 管理端可查询审计记录，筛选时间范围、操作者、动作、对象 |
| G15-3 | 记录保留 365 天 |
| G15-4 | 审计写入失败时，这次管理操作按失败处理，不出现“操作成功但没留痕” |
| G15-5 | 权限：`mail.audit.read` |

### FP-G16 权限点（M4）

| 权限点 | 含义 |
|---|---|
| `mail.domain.read`、`mail.domain.manage` | 域名查看、域名管理（含 DKIM 密钥） |
| `mail.account.read`、`mail.account.manage` | 邮箱查看、邮箱管理 |
| `mail.alias.read`、`mail.alias.manage` | 别名查看、别名管理 |
| `mail.forward.read`、`mail.forward.manage` | 转发查看、转发管理 |
| `mail.blocklist.read`、`mail.blocklist.manage` | 黑白名单查看、黑白名单管理 |
| `mail.policy.read`、`mail.policy.manage` | 出站限额查看、出站限额管理 |
| `mail.queue.read`、`mail.queue.manage` | 队列查看、队列操作 |
| `mail.log.read` | 投递日志、登录日志、垃圾评分记录 |
| `mail.status.read` | 系统状态 |
| `mail.settings.read`、`mail.settings.manage` | 全局设置查看、全局设置管理 |
| `mail.audit.read` | 审计记录 |

| 编号 | 规则 |
|---|---|
| G16-1 | 权限点在 IAM 的权限清单里登记，应用标识为 mail |
| G16-2 | 权限通过角色分配，不逐人分配 |
| G16-3 | 平台超级管理员默认拥有全部权限 |

### FP-G17 插件接入（M4）

| 编号 | 规则 |
|---|---|
| G17-1 | 新建插件工程 mail-manage-web，基于底座 base-manage-web，接入平台门户 |
| G17-2 | 一级菜单“邮件”，下设：域名、邮箱、别名、转发、黑白名单、出站限额、队列、投递日志、登录日志、垃圾评分记录、系统状态、全局设置、审计记录 |
| G17-3 | 没有对应权限的菜单项不显示 |
| G17-4 | 现有的“推送记录”页属于 IAM 的验证码邮件，保留在原位置，不在本插件重复 |

### FP-G18 管理员不能查看成员邮件内容（M2）

| 编号 | 规则 |
|---|---|
| G18-1 | 管理端的任何页面、任何接口都不返回邮件正文和附件内容 |
| G18-2 | 投递日志不记录邮件主题 |
| G18-3 | 邮箱详情页只有用量、别名、状态等元数据 |
| G18-4 | 控制面为了实现成员接口而具备访问邮箱的能力，这部分能力不得被管理接口调用。代码评审把这一条作为必查项 |
