# 邮箱账号

> v0.2 草案；目标态，未实施。覆盖功能点 FP-M。规则编号的前缀与 [PRD](../PRD.md) 第 6 节的功能点编号一致。

[需求基线](../PRD.md) · [技术设计](../tech/04-账号与认证.md) · [域导航](../README.md)

## 1. 开通与同步

### FP-M01 开通邮箱（M2）

| 编号 | 规则 |
|---|---|
| M01-1 | 管理员可为任意 IAM 用户开通邮箱，前提是该用户存在且状态正常。一个用户最多一个邮箱 |
| M01-2 | 开通时生成主地址：账号名加默认域。账号名规则见 FP-M06 |
| M01-3 | 开通时必须设置初始密码：管理员输入，或由系统生成临时密码 |
| M01-4 | 重复开通同一个用户时返回“已开通”，不报错，不改动已有数据 |
| M01-5 | 开通后邮箱状态为正常，立即可用 |
| M01-6 | 开通记管理审计 |

### FP-M02 自动开通范围（M4）

| 编号 | 规则 |
|---|---|
| M02-1 | 全局设置“自动开通范围”有三个取值：指定组织的成员、手动开通、全部 IAM 用户。默认是指定组织的成员 |
| M02-2 | 选“指定组织的成员”时，管理员选择一个或多个组织，这些组织的成员自动获得邮箱 |
| M02-3 | 选“手动开通”时，只有管理员开通的用户才有邮箱 |
| M02-4 | 选“全部 IAM 用户”时，每个状态正常的 IAM 用户自动获得邮箱。面向外部用户的产品不建议用这一项 |
| M02-5 | 调整范围不会回收已有的邮箱。已开通的邮箱保留，是否停用由管理员决定 |

### FP-M03 状态同步（M4）

| 编号 | 规则 |
|---|---|
| M03-1 | 系统定时与 IAM 和 IM 对账，默认每 10 分钟一次，可配置；管理员可在管理端手动触发 |
| M03-2 | IAM 用户被停用或注销时，对应邮箱转为停用：不能登录，来信拒收，不能发信 |
| M03-3 | IAM 用户恢复正常时，对应邮箱恢复正常，除非管理员单独停用了这个邮箱 |
| M03-4 | 邮箱的实际状态由两方面决定：IAM 用户状态，和管理员对这个邮箱的操作。任何一方为停用，邮箱就是停用 |
| M03-5 | 成员被移出组织时邮箱保留，不自动停用。是否停用由管理员决定 |
| M03-06 | IAM 用户被注销时，对应邮箱转为待删除 |
| M03-7 | 对账可重复执行，每次记录新增、更新、失败的数量 |
| M03-8 | 对账失败时告警，不影响已有邮箱的收发和登录 |

## 2. 密码

### FP-M04 邮箱密码（M2）

| 编号 | 规则 |
|---|---|
| M04-1 | 邮箱密码独立于 IAM 登录密码。两者不共享，也不同步 |
| M04-2 | 用户通过 HTTP 接口修改密码，需要提供当前密码 |
| M04-3 | 管理员可重置任意邮箱的密码。重置后生成 12 位以上的随机临时密码，只在管理端显示一次 |
| M04-4 | 临时密码有效期 7 天。过期后不能再用它登录邮件协议。用户可在有效期内通过 HTTP 接口修改密码，需要提供临时密码 |
| M04-5 | 邮件协议本身无法强制用户改密码。临时密码由管理员转交用户，并在转交时提示尽快修改 |
| M04-6 | 修改密码不影响已经登录的会话，新登录使用新密码 |
| M04-7 | 重置密码记管理审计 |
| M04-8 | 自动开通的邮箱没有可用密码。用户通过 HTTP 接口设置初始密码后，才能用标准客户端登录 |
| M04-9 | 设置初始密码只依赖成员登录态。为防止登录态被盗后被人抢先设置，要求登录态经过近期认证，设置成功后通知该用户的 IAM 登录邮箱 |

### FP-M05 密码策略（M2）

| 编号 | 规则 |
|---|---|
| M05-1 | 长度 12 到 128 位 |
| M05-2 | 不得与邮箱地址相同，不得是系统内置的常见弱口令 |
| M05-3 | 通过 HTTP 接口修改时，不得与最近 3 次用过的密码相同。管理员重置不受此限 |
| M05-4 | 密码只保存哈希，任何界面都不能查看明文 |
| M05-5 | 连续输错密码的防护见 FP-X03 |

## 3. 地址

### FP-M06 地址规则（M2）

| 编号 | 规则 |
|---|---|
| M06-1 | 账号名 3 到 32 位，可用字符为小写字母、数字、点、下划线、连字符。首尾必须是字母或数字，点、下划线、连字符不能相邻。不区分大小写，统一按小写保存 |
| M06-2 | 账号名不能是保留字。保留字包括：admin、postmaster、abuse、webmaster、hostmaster、root、system、mailer-daemon、noreply、no-reply、info、support、help、security |
| M06-3 | 每个域的 postmaster 和 abuse 地址自动指向管理员指定的邮箱，保证这两个地址总能收到信 |
| M06-4 | 地址在域内唯一。同一个地址不能既是某个邮箱的主地址，又是另一个邮箱的别名 |
| M06-5 | 邮箱删除后，它的地址在保留期内不能分给别人。保留期满后可以重新分配 |
| M06-6 | 新邮箱的账号名默认用该用户的用户编码。用户可按 FP-M07 改成自定义账号名 |

### FP-M07 修改主地址（M3）

| 编号 | 规则 |
|---|---|
| M07-1 | 用户可把主地址的账号名修改一次，新账号名须符合 FP-M06 |
| M07-2 | 修改后，原地址自动保留为别名，发到原地址的来信不中断 |
| M07-3 | 管理员可修改任意邮箱的主地址，不限次数，同样保留原地址为别名 |
| M07-4 | 修改主地址记审计。用户自助修改也记审计 |

### FP-M08 别名（M2 管理员；M3 用户自助）

| 编号 | 规则 |
|---|---|
| M08-1 | 管理员可为任意邮箱添加别名，别名可以属于任何状态正常的域 |
| M08-2 | 用户可自助添加别名，自助的最多 5 个。一个邮箱的别名总数不超过 20 |
| M08-3 | 发到别名的邮件投到这个邮箱 |
| M08-4 | 别名可以作为发件地址，见 FP-S14 |
| M08-5 | 别名不是独立账号，不能用来登录 |
| M08-6 | 删除别名后，发到该地址的来信被拒收 |

## 4. 状态、删除、配额、权限

### FP-M09 账号状态（M2）

| 编号 | 规则 | 登录 | 收信 | 发信 | 数据 |
|---|---|---|---|---|---|
| M09-1 | 正常 | 允许 | 投递 | 允许 | 保留 |
| M09-2 | 停用 | 拒绝 | 拒收，提示邮箱已停用 | 拒绝 | 保留 |
| M09-3 | 待删除 | 拒绝 | 拒收 | 拒绝 | 保留期内保留 |
| M09-4 | 已删除 | 拒绝 | 拒收，提示地址不存在 | 拒绝 | 已清除 |

| 编号 | 规则 |
|---|---|
| M09-5 | 停用可恢复为正常，邮件数据不变。待删除在保留期内可以恢复为正常 |

### FP-M10 删除（M4）

| 编号 | 规则 |
|---|---|
| M10-1 | 管理员删除邮箱时，邮箱先转为待删除，保留 30 天，可配置 |
| M10-2 | 管理员可以跳过保留期立即彻底删除，需要二次确认 |
| M10-3 | 保留期满后自动彻底删除，清除的内容包括：全部邮件、别名、转发、自动回复、过滤规则、配额记录 |
| M10-4 | 删除和恢复都记管理审计 |

### FP-M11 容量配额（M2）

| 编号 | 规则 |
|---|---|
| M11-1 | 每个邮箱默认 5 GB。管理员可修改全局默认值，也可给单个邮箱设置 |
| M11-2 | 用量是邮箱所有文件夹里邮件的总大小，含附件 |
| M11-3 | 用量超过配额时，新邮件被拒收，已有的邮件不受影响 |
| M11-4 | 用量达到配额的 90% 时，系统发一封提醒到这个邮箱。同一邮箱 7 天内最多提醒一次 |
| M11-5 | 用户通过 HTTP 接口、管理员通过管理端都能查看用量 |

### FP-M12 外发权限（M4）

| 编号 | 规则 |
|---|---|
| M12-1 | 新邮箱默认允许外发 |
| M12-2 | 管理员可对单个邮箱或批量关闭外发权限 |
| M12-3 | 外发权限关闭后，邮箱仍可登录和收信，但不能通过任何通道发信：标准客户端提交被拒，HTTP 接口发送被拒 |
| M12-4 | 变更在 1 分钟内生效 |
| M12-5 | 变更记管理审计 |

### FP-M13 自动清理（M2）

| 编号 | 规则 |
|---|---|
| M13-1 | 已删除文件夹和垃圾邮件文件夹里的邮件保留 30 天，之后每日清理一次，可配置 |
| M13-2 | 清理后的邮件不可恢复 |

### FP-M14 跨域别名（M4）

规则见 M08-1。
