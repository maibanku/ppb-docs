# 域名与收发

> v0.2 草案；目标态，未实施。覆盖功能点 FP-D、FP-S、FP-C。规则编号的前缀与 [PRD](../PRD.md) 第 6 节的功能点编号一致。

[需求基线](../PRD.md) · [技术设计](../tech/05-投递与反垃圾.md) · [域导航](../README.md)

## 1. 域名（FP-D）

### FP-D01 邮件域管理（M2）

| 编号 | 规则 |
|---|---|
| D01-1 | 管理员可添加邮件域。域名为合法域名，转小写保存，全局唯一 |
| D01-2 | 域有两种状态：正常、停用。停用的域不收也不发 |
| D01-3 | 系统里有且只有一个默认域。新开邮箱的主地址默认落在默认域 |
| D01-4 | 第一个添加的域自动成为默认域。默认域不能停用或删除 |
| D01-5 | 只有当域下没有邮箱和别名时才能删除；否则拒绝并说明剩余数量 |
| D01-6 | 添加域时自动生成 DKIM 密钥 |
| D01-7 | 添加、停用、启用、删除、设默认域都记管理审计 |

### FP-D02 对外主机名与 DNS 记录清单（M2）

| 编号 | 规则 |
|---|---|
| D02-1 | 系统级登记一个对外主机名和一个公网 IP，所有域共用 |
| D02-2 | 添加域后，系统给出这个域需要配置的 DNS 记录：MX、SPF、DKIM、DMARC |
| D02-3 | 主机名自身的 A 或 AAAA 记录和 PTR 记录作为全局检查项展示一次 |
| D02-4 | 主机名和 IP 是部署配置，线上页面不能修改。改动部署配置后，管理端显著提示需要同步修改 DNS，并自动重新执行一次全局检查 |

### FP-D03 DNS 校验（M2）

| 编号 | 规则 |
|---|---|
| D03-1 | 校验项：MX 指向登记的主机名；SPF 含登记的 IP 或本主机；当前选择器的 DKIM 公钥与本地密钥一致；DMARC 记录存在；主机名解析到登记的 IP；PTR 反向解析到主机名 |
| D03-2 | 触发时机：添加或修改域后自动执行；每日定时执行；管理端手动执行 |
| D03-3 | 每项结果为通过、失败或未检测，记录检测时间和不含敏感信息的说明 |
| D03-4 | 校验未通过不阻止收发，但管理端在域名列表和系统状态页显著提示 |
| D03-5 | 查询走公共递归 DNS，单项超时 10 秒，整轮不超过 60 秒 |

### FP-D04 DKIM 密钥（M2）

| 编号 | 规则 |
|---|---|
| D04-1 | 每个域一对 RSA 2048 位密钥。私钥只保存在邮件服务器的密钥目录，文件权限仅服务可读 |
| D04-2 | 管理端只显示公钥的 DNS TXT 记录值，私钥不可导出、不可下载 |
| D04-3 | 轮换时生成新选择器和新密钥；旧选择器保留，直到管理员手动删除 |
| D04-4 | 删除旧选择器前提示确认其 DNS 记录已移除 |
| D04-5 | 私钥文件纳入备份 |

### FP-D05 TLS 证书（M2）

| 编号 | 规则 |
|---|---|
| D05-1 | 对外主机名使用一张证书，Postfix 和 Dovecot 共用 |
| D05-2 | 证书由服务器上的 ACME 客户端申请和续期，通过挂载目录提供给各组件；续期后组件自动重新加载 |
| D05-3 | 管理端显示证书到期时间和剩余天数；剩余 15 天以内产生告警 |
| D05-4 | 所有对外 TLS 连接最低版本为 1.2 |

### FP-D06 多域（M4）

| 编号 | 规则 |
|---|---|
| D06-1 | 多个域可同时收发 |
| D06-2 | 每个邮箱属于一个域，即主地址所在的域 |
| D06-3 | 别名可以属于任何已添加且正常的域 |

## 2. 收发（FP-S）

### FP-S01 公网入站（M2）

| 编号 | 规则 |
|---|---|
| S01-1 | 25 端口接收发往本系统已添加且状态正常的域的邮件 |
| S01-2 | 收件人不是任何主地址或别名时，在收件人阶段返回 550 拒收 |
| S01-3 | 收件人的账号已停用或待删除时返回 550 拒收，提示邮箱已停用 |
| S01-4 | 通过垃圾评分的邮件投到收件箱；被评为垃圾的投到垃圾邮件文件夹 |
| S01-5 | 投递遇到临时故障（磁盘满、数据库不可用）时返回 4xx，由发件方稍后重试，不丢信 |
| S01-6 | 收件邮箱配额已满时返回 552 拒收，并说明容量已满 |

### FP-S02 入站加密（M2）

| 编号 | 规则 |
|---|---|
| S02-1 | 25 端口支持 STARTTLS，不强制，以兼容所有发件方 |
| S02-2 | 明文连接也接收，这是公网邮件的通行做法；敏感信息不应出现在邮件正文，属使用约定 |

### FP-S03 出站投递（M2）

| 编号 | 规则 |
|---|---|
| S03-1 | 已认证用户提交的邮件，以及可信提交入口提交的邮件，进入出站队列，直投收件方的邮件服务器 |
| S03-2 | 临时失败（对方返回 4xx、连接超时、对方暂不可达）按退避重试，间隔从几分钟逐步加长 |
| S03-3 | 最长排队 3 天，可配置；超期仍未成功则退信 |
| S03-4 | 永久失败（对方返回 5xx、收件人不存在、域名不存在）立即退信 |
| S03-5 | 退信发给原发件人，发件地址是主机名下的系统账号，内容包含失败原因和原邮件头 |
| S03-6 | 退信本身不会再触发退信 |
| S03-7 | 出站连接使用对外主机名向对方表明身份 |

### FP-S04 出站加密（M2）

| 编号 | 规则 |
|---|---|
| S04-1 | 出站支持机会加密：对方支持 STARTTLS 就加密 |
| S04-2 | 投递日志记录每封出站邮件是否加密 |

### FP-S05 出站 DKIM 签名（M2）

| 编号 | 规则 |
|---|---|
| S05-1 | 所有从本系统发出的邮件都用发件域的密钥做 DKIM 签名，包括标准客户端提交和 HTTP 接口发送 |
| S05-2 | 签名域与 From 地址的域一致 |
| S05-3 | 只是经过本系统的外部邮件不签名 |

### FP-S06 入站校验（M2）

| 编号 | 规则 |
|---|---|
| S06-1 | 入站邮件做 SPF、DKIM、DMARC 校验，结果写入邮件头 |
| S06-2 | 校验结果参与垃圾评分 |
| S06-3 | 发件域的 DMARC 策略是拒绝，且校验未通过时，拒收该邮件 |

### FP-S07 垃圾评分（M2）

| 编号 | 规则 |
|---|---|
| S07-1 | 入站邮件逐封评分 |
| S07-2 | 评分 15 分及以上拒收；6 分到 15 分标记为垃圾并投到垃圾邮件文件夹；6 分以下正常投递。阈值可配置 |
| S07-3 | 评分 4 分以上且发件方信誉未知的邮件可启用灰名单，即临时拒收一次，等对方重发再接收。默认开启，可关闭 |
| S07-4 | 垃圾邮件文件夹里的邮件保留 30 天，之后自动清除 |
| S07-5 | 每封入站邮件的评分、处置结果和命中的主要规则可在管理端查看 |

### FP-S08 黑名单（M4）

| 编号 | 规则 |
|---|---|
| S08-1 | 全局黑名单分两种：发件人地址、发件域 |
| S08-2 | 入站邮件的发件人命中黑名单时拒收 |
| S08-3 | 黑名单只对入站生效，不影响出站 |
| S08-4 | 黑名单变更后 1 分钟内生效 |

### FP-S09 病毒扫描（M5，可选）

| 编号 | 规则 |
|---|---|
| S09-1 | 默认关闭。开启后入站邮件先做病毒扫描 |
| S09-2 | 检出病毒的邮件拒收，并记入投递日志 |
| S09-3 | 病毒库每日自动更新 |

### FP-S10 退信（M2）

规则见 S03-5 和 S03-6。

### FP-S11 大小与数量限制（M2）

| 编号 | 规则 |
|---|---|
| S11-1 | 单封邮件大小上限默认 50 MB，可配置。超限在数据阶段返回 552 |
| S11-2 | 每封邮件的收件人总数（含抄送和密送）上限：标准客户端 200，HTTP 接口 100 |
| S11-3 | 超限拒绝时返回明确的错误信息 |

### FP-S12 出站频率限制（M4）

| 编号 | 规则 |
|---|---|
| S12-1 | 每个账号默认每小时最多向 200 个收件人发信，每天最多 1000 个。按收件人数计，不按封数 |
| S12-2 | 管理员可修改全局默认值，也可给单个账号设覆盖值 |
| S12-3 | 标准客户端提交时超限，返回 451 临时拒绝，提示出站额度已用完 |
| S12-4 | HTTP 接口发送时超限，返回 429 |
| S12-5 | 限额判定服务不可用时放行并告警，不因此阻断全员发信 |
| S12-6 | 外发权限被关闭的账号，提交时直接拒绝 |

### FP-S13 标准邮件客户端（M2）

| 编号 | 规则 |
|---|---|
| S13-1 | IMAP：143 端口支持 STARTTLS，993 端口为隐式 TLS |
| S13-2 | SMTP 提交：587 端口支持 STARTTLS，465 端口为隐式 TLS，都必须认证 |
| S13-3 | POP3 默认关闭。管理员可开启，开启后 110 端口支持 STARTTLS，995 端口为隐式 TLS |
| S13-4 | 只有建立了 TLS 连接之后才允许认证 |
| S13-5 | 认证使用邮箱地址和邮箱密码 |
| S13-6 | 协议能力由 Dovecot 和 Postfix 提供，包括空闲推送、增量同步、移动、特殊用途文件夹 |
| S13-7 | 客户端收到的证书域名与对外主机名一致 |

### FP-S14 发件人伪造防护（M2）

| 编号 | 规则 |
|---|---|
| S14-1 | 认证用户提交的邮件，From 地址必须是本人的主地址或别名，否则拒绝 |
| S14-2 | 拒绝时返回 554，说明发件人不匹配 |

### FP-S15 标准文件夹（M2）

| 编号 | 规则 |
|---|---|
| S15-1 | 每个邮箱自动创建：收件箱、已发送、草稿、已删除、垃圾邮件 |
| S15-2 | 标准文件夹带特殊用途标记，客户端能把它们识别为对应文件夹 |
| S15-3 | 标准文件夹不能删除或重命名 |

### FP-S16 自动回复（M3）

| 编号 | 规则 |
|---|---|
| S16-1 | 用户可设置自动回复，包含：是否启用、开始时间、结束时间、主题、正文 |
| S16-2 | 正文为纯文本，不超过 5000 字 |
| S16-3 | 同一外部发件人在 7 天内只收到一次自动回复 |
| S16-4 | 不对群发、自动回复、退信类邮件回复，避免循环 |
| S16-5 | 结束时间过后自动停止；未设结束时间则一直生效，直到用户关闭 |

### FP-S17 服务端过滤规则（M3）

| 编号 | 规则 |
|---|---|
| S17-1 | 每个用户最多 50 条规则，按顺序执行，可调整顺序 |
| S17-2 | 条件：发件人包含、收件人包含、主题包含、邮件大小超过。每条规则的条件之间是“并且”关系 |
| S17-3 | 动作：移动到指定文件夹、标星、标为已读、转发到指定地址、删除 |
| S17-4 | 删除动作把邮件放进已删除文件夹，不直接永久删除 |
| S17-5 | 规则在邮件投递时由服务器执行，与客户端是否在线无关 |
| S17-6 | 转发动作只在管理员允许用户转发时可用 |
| S17-7 | 规则按顺序匹配，一封邮件只按第一条命中的规则处理 |
| S17-8 | 过滤规则里的转发地址不需要验证，因为规则是用户登录后设置的 |

### FP-S18 转发（M3）

| 编号 | 规则 |
|---|---|
| S18-1 | 用户可设置一个转发地址，并选择是否在本邮箱保留副本 |
| S18-2 | 默认保留副本 |
| S18-3 | 转发地址需要先验证：系统发一封确认信，用户点其中的链接后生效。未验证的地址不转发 |
| S18-4 | 管理员可在全局设置里关闭用户自助转发 |
| S18-5 | 管理员可替用户设置转发，无须验证 |

## 3. 客户端自动配置（FP-C）

### FP-C01 自动配置记录（M5，可选）

| 编号 | 规则 |
|---|---|
| C01-1 | 为每个域发布 IMAP 和 SMTP 提交的 SRV 记录，支持这种发现方式的客户端可自动填好服务器和端口 |
| C01-2 | 自动配置文件通过 HTTPS 提供，内容只有服务器名、端口和加密方式，不含任何凭据 |
