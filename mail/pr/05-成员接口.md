# 成员接口

> v0.2 草案；目标态，未实施。覆盖功能点 FP-A。规则编号的前缀与 [PRD](../PRD.md) 第 6 节的功能点编号一致。全部在 M3 交付。

[需求基线](../PRD.md) · [技术设计](../tech/06-成员接口设计.md) · [域导航](../README.md)

## 0. 通用规则

| 编号 | 规则 |
|---|---|
| A00-1 | 所有成员接口都要求平台统一的成员登录态。身份来自登录态，不从请求参数里取 |
| A00-2 | 每封邮件用一个不透明字符串标识。标识由服务端生成，绑定邮箱，客户端不能自己构造 |
| A00-3 | 同一封邮件在 HTTP 接口和标准客户端里是同一封。一边标了已读，另一边也是已读 |
| A00-4 | 列表接口按页返回，每页默认 50 条，上限 100 条，响应带总数 |
| A00-5 | 时间用 RFC3339 格式的 UTC 时间；标识类字段都是字符串 |
| A00-6 | 用户没有邮箱，或邮箱处于停用、待删除状态时，所有成员接口返回 403 并说明原因 |

## 1. 读取

### FP-A01 邮箱概览（M3）

| 编号 | 规则 |
|---|---|
| A01-1 | 返回每个文件夹的邮件总数和未读数 |
| A01-2 | 返回容量已用字节数和上限字节数 |
| A01-3 | 返回本人的发件地址：主地址和全部别名 |
| A01-4 | 返回本人的显示名和头像，取自平台成员资料。界面上凡是显示“我是谁”的地方都用这一份数据 |

### FP-A02 文件夹管理（M3）

| 编号 | 规则 |
|---|---|
| A02-1 | 列出全部文件夹：标识、名称、特殊用途、所在层级、总数、未读数 |
| A02-2 | 可创建自定义文件夹。名称不超过 64 个字符，同级不能重名，不能与标准文件夹重名 |
| A02-3 | 可在收件箱下建一级子文件夹，最多两层 |
| A02-4 | 自定义文件夹可重命名。标准文件夹不能重命名 |
| A02-5 | 自定义文件夹被删除前必须先清空；非空时拒绝并提示邮件数 |
| A02-6 | 标准文件夹不能删除 |

### FP-A03 邮件列表（M3）

| 编号 | 规则 |
|---|---|
| A03-1 | 按文件夹列出邮件，按时间倒序，最新的在前 |
| A03-2 | 每封返回：标识、会话标识、主题、发件人、时间、是否未读、是否星标、是否带附件、大小、正文摘要 |
| A03-3 | 正文摘要取纯文本正文的前 100 个字符 |
| A03-4 | 可按条件筛选：仅未读、仅星标、仅带附件、时间范围 |
| A03-5 | 可搜索：关键字匹配发件人、收件人、主题、正文、附件名。搜索由服务器执行，可叠加筛选条件 |
| A03-6 | 搜索结果的排序与普通列表相同，按时间倒序 |

### FP-A04 读邮件（M3）

| 编号 | 规则 |
|---|---|
| A04-1 | 返回：主题、发件人、收件人、抄送、时间、正文、附件清单、未读和星标标记、所在文件夹 |
| A04-2 | 正文同时给出纯文本和 HTML 两种形式；原邮件没有 HTML 时 HTML 为空 |
| A04-3 | HTML 正文经过净化才返回：移除脚本、内联事件、表单、框架和插件嵌入。图片引用保留，是否加载由客户端决定 |
| A04-4 | 读邮件不改变已读状态，已读由客户端显式标记 |
| A04-5 | 读别人发来的邮件时，密送地址只显示用户本人那一个；读自己发出的邮件时，密送地址全部显示 |
| A04-6 | 正文里引用的内嵌图片可以按附件标识取回 |
| A04-7 | 邮件编码不是 UTF-8 时，服务端转成 UTF-8 后返回 |

### FP-A05 下载（M3）

| 编号 | 规则 |
|---|---|
| A05-1 | 可下载单个附件，以流式返回 |
| A05-2 | 可下载整封邮件的原始文件，格式为 .eml |
| A05-3 | 下载接口要求登录态，不接受把登录态放在网址里 |
| A05-4 | 附件一律作为下载处理，不在浏览器里直接打开 |

## 2. 写入

### FP-A06 写邮件（M3）

| 编号 | 规则 |
|---|---|
| A06-1 | 支持四种模式：新邮件、回复、全部回复、转发 |
| A06-2 | 回复：收件人是原邮件发件人。全部回复：收件人是原发件人加上原邮件的收件人和抄送，去掉本人在内的重复地址。两种模式都不带上原邮件的密送地址 |
| A06-3 | 回复和全部回复时，主题前加“Re:”，已有该前缀则不重复；服务端写入标准的回复关联头 |
| A06-4 | 转发：主题前加“Fwd:”，原邮件正文作为引用放进新正文，原邮件的附件随新邮件一起发。收件人由用户填写 |
| A06-5 | 字段：收件人、抄送、密送、主题、纯文本正文、HTML 正文、附件标识列表、发件地址。回复和转发时还要带原邮件的标识 |
| A06-6 | 发件地址只能是本人的主地址或别名。不填时用主地址 |
| A06-7 | 收件人地址逐个校验格式，任何一个不合法整封拒绝 |
| A06-8 | 收件人总数（含抄送和密送）不超过 100 个 |
| A06-9 | 主题不超过 256 个字符 |
| A06-10 | HTML 正文在发送前经过与 A04-3 相同的净化 |
| A06-11 | 写邮件的请求要带幂等键，见 A09-3 |

### FP-A07 草稿（M3）

| 编号 | 规则 |
|---|---|
| A07-1 | 草稿的字段与写邮件相同，但收件人可以为空，主题可以为空 |
| A07-2 | 草稿保存在草稿文件夹，可反复更新 |
| A07-3 | 可列出、读取、删除草稿 |
| A07-4 | 从草稿发送成功后，这份草稿被删除 |

### FP-A08 发送前的附件暂存（M3）

| 编号 | 规则 |
|---|---|
| A08-1 | 上传附件后返回附件标识，写邮件时引用这个标识 |
| A08-2 | 单个附件不超过 25 MB；一封邮件的附件合计不超过 35 MB；一封邮件附件不超过 20 个。合计上限按附件原始大小算，编码后整封邮件仍在上限 50 MB 以内 |
| A08-3 | 默认拦截可执行类文件，包括 exe、scr、com、bat、cmd、msi、vbs、js、jar。管理员可在全局设置里关闭拦截 |
| A08-4 | 暂存的附件 24 小时后自动清除 |
| A08-5 | 每个用户的暂存附件合计不超过 100 MB |
| A08-6 | 用户只能使用自己上传的暂存附件 |
| A08-7 | 邮件发送成功后，暂存记录随之删除 |

### FP-A09 发送（M3）

| 编号 | 规则 |
|---|---|
| A09-1 | 发送接口的处理顺序：校验、组装邮件、交给邮件服务器、在已发送文件夹写入副本、返回已发送副本的标识和邮件追踪号 |
| A09-2 | 接口返回成功表示邮件服务器已接收，不表示已经送达对方。送达情况用 FP-A10 查询 |
| A09-3 | 请求带幂等键，长度 1 到 128 个字符。同一个键重复请求返回第一次的结果，不会重复发信。同一个键配不同的内容时返回 409 |
| A09-4 | 邮件服务器没有接收时返回 503，客户端可用同一个幂等键重试 |
| A09-5 | 已发送文件夹写入副本失败不影响发送结果，服务端告警 |
| A09-6 | 外发权限被关闭时返回 403；超出出站限额时返回 429 |
| A09-7 | 发出的邮件不能撤回。已交给邮件服务器的邮件，本系统不再提供撤回 |

### FP-A10 发送状态（M3）

| 编号 | 规则 |
|---|---|
| A10-1 | 用邮件追踪号查询一封已发邮件的投递情况，按收件人分别给出：已投递、投递中、已退信及原因 |
| A10-2 | 数据来自投递日志，有约 1 分钟的延迟 |
| A10-3 | 只能查询自己发出的邮件 |

### FP-A11 标记（M3）

| 编号 | 规则 |
|---|---|
| A11-1 | 可对单封邮件设置或取消已读、星标 |
| A11-2 | 可批量设置，一次最多 500 封 |
| A11-3 | 批量操作部分失败时，返回失败的标识和原因 |

### FP-A12 移动、删除、恢复（M3）

| 编号 | 规则 |
|---|---|
| A12-1 | 可把邮件移动或复制到指定文件夹，单封或批量，一次最多 500 封 |
| A12-2 | 删除是把邮件放进已删除文件夹。已删除文件夹里的邮件 30 天后自动清除 |
| A12-3 | 已删除文件夹里的邮件可恢复到删除前所在的文件夹；找不到原文件夹时恢复到收件箱 |
| A12-4 | 彻底删除只对已删除文件夹里的邮件有效，不可恢复，请求里要显式声明彻底删除 |
| A12-5 | 标准文件夹里的邮件同样可以删除，包括已发送和草稿 |
| A12-6 | 移动、删除、恢复的批量操作部分失败时，返回失败的标识和原因 |

## 3. 设置

### FP-A13 自动回复设置（M3）

| 编号 | 规则 |
|---|---|
| A13-1 | 可读取和修改自动回复，字段见 FP-S16 |
| A13-2 | 修改后 1 分钟内生效 |

### FP-A14 转发设置（M3）

| 编号 | 规则 |
|---|---|
| A14-1 | 可设置转发地址和是否保留副本，规则见 FP-S18 |
| A14-2 | 提交转发地址后，系统向该地址发确认信。用户点击信里的链接后转发才生效 |
| A14-3 | 可重新发送确认信，可删除转发设置 |
| A14-4 | 确认链接 48 小时内有效，只能使用一次 |
| A14-5 | 管理员关闭了用户自助转发时，接口返回 403 |

### FP-A15 过滤规则（M3）

| 编号 | 规则 |
|---|---|
| A15-1 | 可增、删、改过滤规则，可调整顺序，规则见 FP-S17 |
| A15-2 | 修改后 1 分钟内生效 |
| A15-3 | 用户的规则编译失败时不生效，接口返回错误原因，原有规则继续有效 |

### FP-A16 邮箱密码（M3）

| 编号 | 规则 |
|---|---|
| A16-1 | 修改密码的规则见 FP-M04 和 FP-M05，需要提供当前密码 |
| A16-2 | 没有可用密码的邮箱可调用设置初始密码接口：自动开通的邮箱，或临时密码已过期的邮箱。这个接口不要求当前密码，但要求成员登录态经过近期认证 |
| A16-3 | 成员接口的登录态是平台统一的成员身份，不使用邮箱密码 |

### FP-A17 会话视图（M3）

| 编号 | 规则 |
|---|---|
| A17-1 | 列表可按会话聚合，返回每个会话的首封标识、参与人、主题、邮件数、未读数、最后活动时间 |
| A17-2 | 可展开一个会话，返回其中的全部邮件，包括不同文件夹里的 |
| A17-3 | 会话按邮件的标准回复关联头聚合。没有关联头的邮件各自成一个会话 |
| A17-4 | 一封邮件只属于一个会话 |

### FP-A18 鉴权（M3）

| 编号 | 规则 |
|---|---|
| A18-1 | 没有登录态的请求返回 401 |
| A18-2 | 只能访问自己邮箱的数据。访问别人的邮件时返回 404，不透露该邮件是否存在 |
| A18-3 | 登录态失效或被撤销后，请求立即被拒绝 |

## 4. 主地址与别名

### FP-A19 主地址与别名自助（M3）

| 编号 | 规则 |
|---|---|
| A19-1 | 用户可把主地址的账号名修改一次，规则见 FP-M07。修改后，原地址自动成为别名，不能被用户删除 |
| A19-2 | 用户可自助添加别名，规则见 FP-M08。别名可以属于任何状态正常的域 |
| A19-3 | 用户只能删除自己添加的别名。管理员添加的和修改主地址后保留的别名不能删除 |
| A19-4 | 修改主地址后，用户要用新地址登录标准客户端。已经登录的会话不受影响 |
| A19-5 | 这些操作都记审计 |
