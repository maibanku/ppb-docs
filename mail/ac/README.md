## 证据放哪里

邮箱系统的证据放在本目录的 evidence 子目录下，按阶段分文件夹：evidence/M1、evidence/M2，以此类推。每个文件名以它对应的验收条目编号开头，例如 MAC-21-inbound-550.txt。系统通知邮件的缺口修复证据放在 evidence/M0。

实施进度和证据的对应关系记在 [实施进度](../implementation/PROGRESS.md)。
