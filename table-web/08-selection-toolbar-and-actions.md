# 08 选择、序号、工具栏与操作

更新：2026-11-19。状态：待实施规范。执行前先读 [README](./README.md)，本文不代表功能已实现。

> 本轮范围：在现有 ProTable 上增量实现本专题能力，保留旧公开 API 与请求状态；下述目标命名为示意，不要求引入独立列表组件或现有状态逻辑。以 [00 调整清单](./00-style-refactor-checklist.md) 为总范围。

### 选择

以稳定 rowKey 维护 selectedKeys，行对象只作展示缓存。大整数 ID 使用字符串，保留旧代码对不安全数值 ID 的保护。重复或缺失 key 的行不可参与可靠跨页选择，开发环境提示配置问题。

选择列最左，序号列随后，两者独立开关。序号支持当前页、连续编号、自定义；页码模式连续编号为 `(page-1)*pageSize+rowIndex+1`，游标模式不要伪造未知全局位置。

翻页是否保留选择可配置；提交新筛选、重置、排序默认清选择，scopeKey 或账号变化必须清选择。新现有状态逻辑将“跨页保留”与“跨查询保留”分开，默认不跨查询；旧 reserveSelection 行为在兼容层保持并注明差异。

默认全选仅当前页。选择全部查询结果属于单独的后端批量协议，本轮不实现。批量写接口重新验证状态和权限，不能信任缓存行对象。

### 操作

工具栏左侧普通操作，右侧辅助操作/列设置；提供已选数量和清空入口，未选择禁用批量操作。新增等按钮占筛选下方独立一行，不等同于表格内编辑新增行。

新页面负责权限、危险操作确认、执行中禁用、成功反馈和写后刷新。ProDataTable 不处理用户状态机。旧 actions/batchActions 的权限、confirm、danger、refreshAfter、异常反馈通过兼容适配器维持。

## 独立开关与布局

selection 支持 none/single/multiple；single 不显示全选复选框。selectable(row) 由业务声明，缺失或不安全 key 即使业务允许也不能加入跨页选择。序号独立于选择开关，分页连续编号与本页编号分别验证。

工具栏普通操作、批量操作、辅助操作通过具名插槽或操作描述定义；没有任何内容时整行不占位。默认不擅自加刷新、导出等按钮，具体页面声明才展示；保留 refresh 方法供操作和错误重试调用。

## 操作执行

通用展示接收 visible/disabled/loading/handler 等已解析能力；保留现有权限接入，不因样式调整搬迁权限逻辑。行操作 busy 按 actionKey+rowKey 区分，是否禁用其他操作由业务声明；旧兼容层维持原全局 busy 行为。失败显示错误并恢复可操作状态，取消确认不请求。

批量操作明确接收 selectedKeys 还是已缓存 rows；远程跨页时不能把缓存对象当成完整最新记录。清选择在成功时执行；失败保留选择便于重试。旧 BatchAction 的 rows 约定通过兼容适配维持，升级成 keys 接口需明确迁移。

## 验收

无选择/单选/复选、不可选行、当前页全选、跨页保留、查询清理、范围强制清理；序号与分页变化正确；工具栏空时不占位；权限禁止按钮不可触发；成功刷新与异常恢复只执行一次。
