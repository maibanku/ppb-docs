# 04 筛选扩展、时间与折叠布局

更新：2026-11-19。状态：待实施规范。执行前先读 [README](./README.md)，本文不代表功能已实现。

> 本轮范围：在现有 ProTable 上增量实现本专题能力，保留旧公开 API 与请求状态；下述目标命名为示意，不要求引入独立列表组件或现有状态逻辑。以 [00 调整清单](./00-style-refactor-checklist.md) 为总范围。

## 筛选组件规范

### 首轮必做控件

input、number、number-range、select（单/多选、静态及远程选项）、date、date-range、datetime、datetime-range、time、time-range、tree-select、cascader、custom 插槽。年月选择可作为日期控件配置。单选组、复选组、开关和 tags 可通过控件注册表或插槽扩展，不在容器中持续堆业务分支。

字段配置需要支持：key、label、type、defaultValue、placeholder、order、span、minWidth、disabled、visible、校验、参数序列化；各控件使用判别联合定义专属 props，避免一个包含大量 any 的通用字段类型。字段 key 唯一。

下拉支持静态选项、字典或远程 options loader、label/value 映射、搜索、loading/error/retry；关联字段上级变化时清理无效下级值并作废旧选项请求。分页选项加载作为后续增强。

参数处理支持去首尾空格、字段重命名、范围拆分、数组序列化；自定义 serializer 不得覆盖固定范围。必填、数字上下界、起止顺序、最大时间跨度和自定义异步校验统一接入。

### 时间规则

| 快捷项 | 日期时间型口径 |
| --- | --- |
| 今天 | 业务时区当天 00:00:00 至当前时间 |
| 最近一个星期 | 当前时间回退 7 天至当前时间 |
| 最近一个月 | 当前时间回退 1 个日历月至当前时间 |
| 最近三个月 | 当前时间回退 3 个日历月至当前时间 |

快捷项在点击时计算，不能在模块加载时缓存。日历月回退遇月末按目标月末钳制。支持秒级精度、禁止未来、最大跨度和自定义快捷项。日期字段按整日范围处理，展示格式、控件值格式和接口序列化分别定义。

时区由应用明确配置；兼容路径保持当前接口字符串及包含边界契约，新协议优先说明起始包含、结束排除，不能未经确认把旧 created_to 改为排除边界。以固定时钟验证跨月、月末、跨年和业务时区零点；若支持夏令时地区，明确日历日与 24 小时的区别。

### 折叠与布局

默认一行，按容器可用宽度计算，使用 ResizeObserver；避免仅按屏幕宽度或写死前 N 项。时间范围允许 span=2，字段按 order 稳定排序。标签与输入在一个边框内，左标签、分隔线、右控件。

查询、重置、展开操作始终可见，窄容器可独立成行。无额外条件不显示展开。折叠只改变布局，不清空、不卸载丢值、不请求；收起显示隐藏区域内已生效条件数量，草稿与已生效条件不要混算。提供字段、标签及操作区插槽。

## 控件能力清单

| 控件 | 补充配置 |
| --- | --- |
| input / tags | trim、长度、清空、多值去重；tags 可先通过注册控件提供 |
| number / number-range | min/max/step/precision，0 为有效条件 |
| select | multiple/filterable/clearable、静态/字典/远程、分组、label/value 映射 |
| radio / checkbox / switch | 布尔或枚举映射；可注册控件，不能把 false 丢弃 |
| date / datetime / range | 展示和值格式、秒级精度、快捷项、禁用日期、时区、最大跨度 |
| time / time-range | 时分秒、起止校验、跨日是否允许由业务声明 |
| tree-select / cascader | 节点 key 映射、单多选、父子选择规则、关联条件 |
| custom | 页面提供控件，统一读写 model、disabled、error |

基础实现至少交付正文列出的首轮控件；可注册类型也需给出一个真实可运行注册示例，不能只留空扩展点。

## 字段状态与查询语义

visible=false 只表示隐藏，不能默认清值；需要随条件失效的字段显式配置 activeWhen/dependencies，依赖失效时清值且不参与序列化。区分折叠隐藏、权限禁止和依赖失效三种原因。disabled 不等于无条件提交或移除，按字段协议定义并测试。readonly 控件底层不支持时使用文本展示或专用适配，不盲目透传。

异步校验应校验同一份草稿快照；校验过程中继续编辑时作废本次提交或重新校验，不能将“校验旧值、提交新值”混用。回车仅在适当输入控件提交，不能打断多行输入、下拉选择和输入法合成。

## 条件摘要与保存方案（后续增强）

摘要只来自 appliedFilters，展示友好标签而不是原始 JSON；移除某项=更新草稿和已提交快照并请求一次，其他草稿是否保留需明确。固定业务范围不可移除。方案保存、恢复、重命名、删除按用户/页面/范围/版本隔离，恢复时过滤无效字段和选项，应用方案只请求一次。URL 记忆应使用白名单并避开敏感值；远程选项标签恢复不能无限请求。

## 验收

控件覆盖、数组默认值不变、false/0 保留、字段重命名与区间拆分、联动请求竞态、校验失败零请求；展开收起不丢值；隐藏生效条件计数正确；今天/7天/1个月/3个月秒级出参、月末和业务时区零点通过固定时钟测试。
