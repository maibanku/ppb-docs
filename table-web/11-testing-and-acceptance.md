## 验收矩阵与验证命令

### 九种可操作组合

| 编号 | 组合 | 关键验收 |
| --- | --- | --- |
| 1 | 基础列表 | 同一 ProTable 关闭选择及分页，无空占位 |
| 2 | 筛选 + 表格，无分页 | 查询/重置生效，无分页数据契约明确 |
| 3 | 筛选 + 表格 + 页码分页 | 默认路径，请求一次、真实总数、跳页 |
| 4 | 筛选 + 多选 + 序号 + 分页 | 两列独立，连续编号，选择清理规则 |
| 5 | 工具栏 + 多选 + 批量操作 | 选中计数、禁用、确认、失败和成功刷新 |
| 6 | 多类型筛选 + 展开收起 | 秒级时间、快捷项、窄容器、收起不丢值 |
| 7 | 自定义单元格/表头 + 排序 | 插槽上下文完整，宽度/对齐/排序不失效 |
| 8 | 列设置 + 展开行 | 显隐、顺序、宽度、密度、偏好恢复与版本兼容 |
| 9 | 完整组合 + 展开行 | 筛选、工具栏、选择、序号、行展开和分页配合正常 |

另覆盖本地全集和游标模式；不为了凑九宫格省略数据模式验证。保留现有参考图片，新增截图清楚区分参考与实际实现。

### 必须覆盖的回归

- 草稿未提交翻页不应用；默认值数组不被修改；查询、重置和换页大小只发一次请求。
- 快速查询、失败响应、卸载和范围变化不会让旧请求污染数据、错误或 loading。
- 删除末页最后记录回退有效页；空结果保持合法页码。
- 本地先筛选/排序再分页，源数组不变，computed 切片引用稳定，无递归更新。
- 字符串长 ID、缺失 key、跨页选择及跨范围清理；0 和 false 正确显示。
- 时间快捷项点击实时计算，秒级映射、月末/跨年/时区边界正确。
- 单元格与表头插槽兼容、旧 col 插槽和 actions 正常、手写列不会重复。
- 游标未知总数不显示虚构页数，手动全量失败/到上限不标成已完成。
- 列偏好隔离、损坏存储、增删列、权限列及恢复默认。
- 用户状态正常/停用/注销的原行为、取消确认、失败回弹和写后刷新保持。
