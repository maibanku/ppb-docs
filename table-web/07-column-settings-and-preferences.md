# 07 列设置与用户偏好

更新：2026-11-19。状态：待实施规范。执行前先读 [README](./README.md)，本文不代表功能已实现。

> 本轮范围：在现有 ProTable 上增量实现本专题能力，保留旧公开 API 与请求状态；下述目标命名为示意，不要求引入独立列表组件或现有状态逻辑。以 [00 调整清单](./00-style-refactor-checklist.md) 为总范围。

### 列设置

本轮实现显隐、顺序、宽度、密度及恢复默认；顺序调整至少有上移/下移，拖拽可增强。保留固定区域约束，不允许设置打乱选择列、序号列和强制操作列。

偏好 key 包含用户、页面、业务范围及配置版本。仅保存列 ID、顺序、显隐、宽度、密度，不保存 formatter、插槽、权限结果或整份列定义。读取后与当前允许列合并：去已删列、补新增列、强制必显列、过滤权限列；损坏/不可用存储回退默认。恢复默认清除此作用域偏好。

## 设置面板

工具栏右侧按需显示“列设置”。打开呈现当前允许列，支持显隐、上移下移、宽度与密度、恢复默认。必显列不可取消；权限列不出现在清单。叶子列调整限定于当前父组及固定区域，初版不支持跨组拖动。手写未注册元数据的列不提供设置项。

列显隐、顺序和密度立即预览；宽度拖动结束再保存。设置变化不请求业务列表，窗口尺寸变化也不发请求。不允许全部可读数据列被隐藏而留下只有选择列/操作列的表格。

## 存储协议示意

```ts
interface ListPreference {
  version: number
  columns: Array<{ key: string; visible?: boolean; width?: number }>
  density?: 'compact' | 'default' | 'comfortable'
}
// columns 数组顺序表示用户顺序；不序列化业务函数。
```

key 由应用注入的稳定 userKey/pageKey/scopeKey/version 组成，不在基础组件读取 IAM 会话。版本变化默认清理或通过显式迁移函数恢复；禁止在不同用户或业务范围之间回退读取。

## 恢复算法

1. 从当前列定义与权限结果生成允许列集合。
2. 解析存储并校验版本、类型、重复 key、宽度范围；无效存储回退默认，不阻塞页面。
3. 按已保存顺序恢复仍存在的叶子列，尊重分组和固定区域边界。
4. 新列按默认相对顺序补入，强制必显列显示；删除列与权限列丢弃。
5. 使用最新 label/formatter/slots/权限，绝不从存储恢复这些元数据。
6. 应用后同步设置面板和表格；恢复默认清当前 key，并恢复默认宽度、顺序、显隐、密度。

保存失败只降级为本次会话可用，不让列设置抛错导致白屏。支持 storage 接口注入以便测试，默认本地存储可用；服务端偏好同步是后续能力，不增加无依据接口。

## 验收

隔离用户/页面/范围/版本、损坏 JSON、不可写存储、非法宽度、重复 key、增删列、权限撤销、固定列和分组约束、必显列、恢复默认；偏好应用与列调整都不触发列表请求。
