## 逐入口责任

`baseline/routes.csv` 每一行都必须在最终 `progress/ROUTE-STATUS.csv` 有对应 operationId，字段至少：原 URL、最终服务、最终 HTTP 路径、认证类别、权限规则、审计位置、实现文件、测试名、真实验证证据、提交、状态。

- 原 upstream 为 server-im：HTTP 适配归 IM；含 legacy UserOrg 部门/成员/好友/公告等。
- 原 upstream 为 server-iam：登录/账号/治理/RBAC/审计/会话接口归 IAM。成员登录需要组织查询时，在 IAM 的业务认证协调模块调用 IM RPC；网关不协调。
- 原 upstream 为 server-file：文件管理与流式 API 归文件服务。
- 原 upstream 为 server-camera：Camera 主体业务与管理 HTTP 归 Camera。
- manage/system/health：健康聚合放 IAM/运维服务；网关 `/ping` 只表明代理进程可用，不能伪造下游全部健康。
- 特殊入口：登录/session/oidc-exchange、/iam 直通与业务桥、/ws、文件流、Swagger/静态资源逐一明确承接；不能只改 Registry 内的 105 项。
