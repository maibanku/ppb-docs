## 核心决定

保留现有 Gin、Registry、gRPC、响应信封与权限体系；首先治理路由注册和元数据，再用 todo 域验证契约生成普通 HTTP 适配代码。认证编排、WebSocket、文件流继续使用显式适配器。生成方案未通过兼容验证前，不扩大替换范围。

文档中心只存设计和验收记录，代码修改在 `ppb-base`。现有接口行为以代码和实际请求基线为依据；本文的目标目录、命令和字段不代表已经实现。
