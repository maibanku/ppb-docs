## 5. RPC 实际 upstream 对照（重点核对项）

按 Upstreams 字段 → gRPC 连接（proxy/grpc_clients.go:79-88 NewUpstreams 连接下标：im=conns[0]、file=conns[1]、camera=conns[2]、iam=conns[3]）→ 承接服务：

| Upstreams 字段 | RPC service | 实际承接 | 条数 | 领域事实核对 |
|---|---|---|---|---|
| Todo | todo.TodoService | **server-im**（复用 im 连接） | 6 | ✓ 与「todo 域 RPC 实际由 server-im 承接」一致 |
| UserIam | user.UserService（认证/治理子集） | **server-iam** | 21 | ✓ Login/ManageLogin/Logout/ChangePassword/ListSessions*/GetMyAdminProfile/AdminAuthz/ChangeMyPassword/ListEmailSendLog/ListIamAuditEvents/GetMyPermissions/SetAvatar/GetMyFiles 等 |
| UserOrg | user.UserService（组织子集） | **server-im**（chat 组织域） | 44 | ✓ contacts/profile/preferences/invitations/register/friends/announcements + manage 成员/角色/设置/审计(chat) 等 |
| IM | im.IMService | server-im | 19 | ✓ |
| ChatOrg | im.ChatOrgService | server-im | 0（HTTP 直挂消费：member_auth/oidc_exchange，不经 Registry） | ✓ |
| File | file.FileService | server-file | 12 | ✓ |
| Camera | camera.CameraService | server-camera | 10 | ✓ |
| CameraAdmin | camera.AdminService | server-camera | 19 | ✓ |
| Iam | iam.IamService | server-iam | 0（HTTP 直挂消费：member 登录链/会话撤销/系统健康无关） | ✓ |
| （本地） | —（无下游调用） | 网关自身 | 1 | GET /api/v1/manage/system/health（system_health.go:273-280，并行探测 im/file/iam 健康口；policy=chat/system.read 已挂） |

关键结论：**同一 `user.UserService` service 名下两个承接方**（UserIam→server-iam、UserOrg→server-im）必须逐路由区分——快照 `upstream_client` 字段即实测区分依据，**不得按 RPC service 名推断 upstream**（G5 迁移红线）。camera `/auth/sms` 为同端点两阶段（空 code→SendSmsCode、有 code→LoginBySms，camera_registry.go:76-87），快照记录阶段一 RPC。

## 6. 身份/权限现状

- **member-jwt 链**（auth.Middleware，auth/auth_middleware.go:42）：白名单 15 键匿名放行；member token 必携 sid 且双检查器已装配（IAM auth_sessions 会话锚复检 + ChatOrg 组织域复检，均 fail-closed）；member token 访问 /api/v1/manage 403；操作者身份一律由 JWT claims 覆盖式注入（operatorRPC/operatorBindRPC/subjectRPC），客户端 body/参数自带身份不采信。
- **manage-jwt 链**：auth.Middleware + RequireManage（typ=manage 强校验）+ permguard（internal/permguard）：RoutePolicy 三类（self/app_perm/super_gov）fail-closed；AdminAuthz 缓存以 RbacVersion 版本戳（rev:&lt;n&gt;）一致性为前提；`UncodedManageRoutes` 非空即拒绝启动（main.go:100-103）。
- **camera-subject 链**（proxy/camera_auth.go:40）：cameraSecret 验签 + typ=camera + subj_ 前缀；4 键匿名白名单；secret 缺省 = subject 面 fail-closed 401；主体经 x-ppb-subject metadata 下传。
- **/iam/* 直通**：IAM 自治域（HttpOnly Cookie 会话 + IAM 自有错误信封），网关不解读不改写；业务桥按 IAM context 逐请求新鲜授权。
- **/ws**：升级时 member JWT 校验一次。
- Registry 内 member/camera 面（60 条）**无授权策略模型**（现状即 JWT 身份 + 下游资源裁决）——G2 需补显式策略，迁移前不得视为 public。
