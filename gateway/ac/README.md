# 网关改造验收标准

初始状态：全部待执行。本文件定义完成条件，不记录虚构的通过结果。

## 验收矩阵

| ID | 验收内容 | 必要证据 |
|---|---|---|
| AC-01 | 重复路由及同构/歧义模板拒绝；精确优先不变 | 对应失败/成功测试与退出码 |
| AC-02 | 目录覆盖 Registry、直接 HTTP、WS、文件、认证特殊入口 | 路由导出与真实入口对照，无未解释缺项 |
| AC-03 | 缺失身份/策略、重复 operationId、孤立策略拒绝 | 启动/构建负向测试 |
| AC-04 | todo 六条接口生成可复现，未标注 RPC 不公开 | 固定依赖、生成命令、干净生成差异 |
| AC-05 | 当前请求和响应兼容 | 旧/新 fixture 比对：字段、类型、空值、参数、信封、错误码 |
| AC-06 | 身份可信且越权被拒绝 | 伪造 operator/header、错身份、越权资源、撤销/过期令牌测试 |
| AC-07 | 服务治理不退化 | deadline/cancel、request ID、内部凭证、超时/不可用错误验证 |
| AC-08 | todo 真实业务闭环 | 真实本地账号创建→读取→更新→状态变更→删除→不可见，列表过滤验证 |
| AC-09 | 文档真实一致 | OpenAPI 3.0 校验、operationId 唯一、目录与运行路由对应 |
| AC-10 | 可安全回滚 | 切换旧处理器，既有客户端同请求可用，写请求无双调用 |
| AC-11 | 受影响现有测试不退化 | gateway 完整测试；相关 idl/业务服务测试结果 |
| AC-12 | 各域推广独立验收 | 每域映射表、提交、测试与回滚证据 |

以下为现有工具/模块的基础命令，不代表已经执行。先核实本机 Go/Buf 版本和依赖；新增目录工具的命令由实施者在交付中补齐。


Buf 现有规则如有历史失败，记录基线并区分新增失败，不顺带批量格式化无关 Proto。生成验证应在干净 worktree 内进行并检查差异，避免误改他人正在使用的生成文件。

真实闭环使用现有本地 Docker 环境和真实 IAM/IM 服务；不在文档、命令输出或提交里存密码/token。测试数据使用唯一前缀，记录清理结果；不要删除已有聊天或用户数据。错误注入可以用测试专用可控上游，必须标注与真实环境验证的区别。

## 完成门槛

G0–G4 完成需 AC-01 至 AC-11 全部有有效证据；G5 各域推广另需 AC-12。任何 FAIL、BLOCKED、NOT_RUN 都必须列入剩余工作，不能标成全部验收通过。生成成功、编译成功、进程运行或 UI 可打开，单独都不构成业务验收。

完成报告必须说明：已迁移域、保留手写接口、兼容验证范围、真实环境结果、提交 SHA、回滚方式及尚未实施的内容。
