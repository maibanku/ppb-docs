# Wardrobe · AI 衣柜产品文档

衣序是面向个人用户的 AI 衣柜 App：用自己的衣服快速完成搭配，支持照片拆分、单品整理、局部换搭与穿着记录。

## 文档

- [产品需求文档 PRD v1.0](./PRD.md)：目标用户、功能范围、App/Web 交互、本地与云端架构、数据模型、AI 评估、验收与发布计划。

- [具体需求点](./具体需求点/README.md)：8 个模块、37 条需求，按功能分工。
- [开发软件的验收标准](./开发软件的验收标准/README.md)：对应 37 条用例、发布门槛、追踪矩阵和执行记录模板。

## 已确定的设计方向

- 极简、少按钮，手机只有“穿搭、衣橱”两个一级入口。
- 参考 WOO 的立体展示方向；三维能力需验证，二维拼搭始终可用。
- 照片中的上衣、裤子、鞋、包等拆分后，逐项确认入库，再由 AI 组合。
- 本地优先，云端增强；云端处理与全量同步分别授权。
- Web 个人整理端与运营后台权限分离。

## 阅读与执行

1. 产品/设计先阅读 PRD 第 1–6 节，确定范围和界面行为。
2. 研发阅读第 7–9 节，评审本地能力、同步、AI 任务和权限。
3. AI/测试阅读第 10、14 节，冻结评估集与验收条件。
4. 项目负责人阅读第 13、15 节，明确排期前需要确认的事项。

P0 为首版交付范围；P1/P2 为后续规划。文档中的性能数值是拟定目标，并非已实现结果。当前目录交付需求文档，不包含可运行 App；会话中的概念图片尚未复制到仓库。
