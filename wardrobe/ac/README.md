## 执行入口

1. 阅读[验收总则与发布门槛](./00-验收总则与发布门槛.md)，冻结版本、范围、环境和测试样本。
2. 按下表逐模块执行 43 条用例。
3. 用[需求追踪矩阵](./需求追踪矩阵.md)检查范围覆盖，用[执行记录模板](./验收执行记录模板.md)保存每次版本的实测结果。
4. 收集运行证据、缺陷和复测结果后出具发布结论。
