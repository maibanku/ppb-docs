# Web 个人衣物整理工作台

版本：v1.0 · 日期：2026-10-26 · 状态：待设计/技术评审，未代表实现。

[返回需求目录](./README.md) · [对应验收用例](../ac/06-Web个人整理工作台.md) · [总 PRD](../PRD.md)

## 范围与来源

W05、W10；FR-09；PRD 第 4.3 节。

P0 单图拆分、分类及基础多选编辑；P1 跨图片高级批量处理和一周计划。

## 目标流程

导入原图/文件包或读取授权同步数据 → 左原图右候选 → 调整分类 → 确认入库 → 选择单品组装。

## 数据和依赖

复用 Garment、Candidate、Outfit 数据契约；浏览器缓存不是永久备份；编辑基于对象版本。

## 逐项需求

### REQ-WEB-01 并排整理

- 规则：左侧原图右侧候选，一个主要确认按钮；候选可逐项改类、改名、取消。
- 场景与输入：可访问个人工作台，准备整套照片。
- 操作与异常边界：上传并拆分，修改两项并取消一项，确认。
- 输出约束：仅确认选中项，来源关系正确；结果不因页面排版丢失字段。
- 验收：TC-WEB-01，详见[对应验收文件](../ac/06-Web个人整理工作台.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。

### REQ-WEB-02 批量编辑边界

- 规则：基础多选仅修改显式选择字段与对象；提交前预览范围。跨图片自动批处理属于 P1。
- 场景与输入：十件衣物，选中其中三件。
- 操作与异常边界：修改三件类别，查看预览；取消，再确认。
- 输出约束：取消无改变；确认仅三件目标字段更新，其他数据不受影响。
- 验收：TC-WEB-02，详见[对应验收文件](../ac/06-Web个人整理工作台.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。

### REQ-WEB-03 跨设备和重连

- 规则：Web 仅访问主动同步/导入的数据；断网草稿可见，未同步状态明确；恢复联网须做版本检查。
- 场景与输入：手机本地另有未同步衣物；Web 已打开已同步对象。
- 操作与异常边界：查看列表，断网编辑并刷新，再连网提交。
- 输出约束：未同步手机衣物不会凭空出现；草稿按约定保存且标明未同步；版本冲突进入解决流程。
- 验收：TC-WEB-03，详见[对应验收文件](../ac/06-Web个人整理工作台.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。

### REQ-WEB-04 按选择组装

- 规则：用户可选择单品发起 AI 组合，锁定项跨端语义一致；无授权不上传，缺类别告知。
- 场景与输入：已有上衣、裤子，云端授权关闭。
- 操作与异常边界：选择裤子为锁定项，先拒绝云端再授权发起组合。
- 输出约束：拒绝保留选择；授权后锁定 ID 不变；缺鞋不虚构；保存可在同步后被手机读取。
- 验收：TC-WEB-04，详见[对应验收文件](../ac/06-Web个人整理工作台.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。
