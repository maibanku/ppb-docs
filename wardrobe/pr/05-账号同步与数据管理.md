# 账号、同步、导出恢复与隐私

版本：v1.0 · 日期：2026-10-26 · 状态：待设计/技术评审，未代表实现。

[返回需求目录](./README.md) · [对应验收用例](../ac/05-账号同步与数据管理.md) · [总 PRD](../PRD.md)

## 范围与来源

W06；FR-01、FR-08、FR-11、FR-12；AC-01、AC-07、AC-08、AC-11、AC-12。

P0；跨设备通过主动同步或文件包，不假设 Web 能读取手机本地文件。

## 目标流程

游客本地使用 → 按需登录 → 预览合并 → 单独开启同步 → 冲突处理；或导出包 → 新设备导入。

## 数据和依赖

稳定 UUID、owner、version、deleted_at/删除墓碑、同步游标；导出包包含版本清单、图片 hash、衣物和搭配关系。

## 逐项需求

### REQ-DAT-01 登录与同步分离

- 规则：取消登录保留上下文；登录不自动上传全部衣橱；游客绑定账号先预览合并，不能覆盖远端衣橱。
- 场景与输入：本地和远端各有两件且一件相似。
- 操作与异常边界：触发高级能力取消登录；再次登录，查看合并并不开启同步。
- 输出约束：上下文保留；相似项不自动删；无未授权全量上传，远端对象保持。
- 验收：TC-DAT-01，详见[对应验收文件](../ac/05-账号同步与数据管理.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。

### REQ-DAT-02 冲突与删除墓碑

- 规则：两端同对象修改不能静默覆盖；删除后旧离线设备同步不能复活。不同对象变更正常合并。
- 场景与输入：手机与 Web 共用账号，双方基于同一版本。
- 操作与异常边界：离线分别改颜色；恢复网络解决冲突；一端删衣，旧设备再连。
- 输出约束：可选择版本或保留副本；删除对象不复活；其他对象变更不丢。
- 验收：TC-DAT-02，详见[对应验收文件](../ac/05-账号同步与数据管理.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。

### REQ-DAT-03 账号隔离

- 规则：本地游客与各账号空间隔离；退出停止同步；保留本机副本不意味着另一账号可见。
- 场景与输入：账号 A 已同步私有衣橱，准备账号 B。
- 操作与异常边界：退出 A 选择保留副本，登录 B，查询列表与资源链接。
- 输出约束：B 不可见 A 图片/记录，旧任务不能写入 B；A 可按策略恢复自己的副本。
- 验收：TC-DAT-03，详见[对应验收文件](../ac/05-账号同步与数据管理.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。

### REQ-DAT-04 导出与恢复

- 规则：导出图片、元数据、搭配和穿着关系；导入校验版本/hash，失败项明确，重复导入不重复创建。
- 场景与输入：含 20 件衣物、5 套搭配、3 条记录的测试库。
- 操作与异常边界：导出到空环境恢复，再重复导入；另导入损坏包。
- 输出约束：数量关系与资源一致；重复导入无重复；损坏项报告，不破坏已有库。
- 验收：TC-DAT-04，详见[对应验收文件](../ac/05-账号同步与数据管理.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。

### REQ-DAT-05 删除范围和撤销授权

- 规则：区分本地副本清理、云端删除与账号删除；开启同步时删除传播使用墓碑。撤销授权停止新上传。
- 场景与输入：存在本地/云端副本与排队任务。
- 操作与异常边界：先取消删除，再执行限定范围删除；撤销上传授权并触发新任务。
- 输出约束：取消不改变数据；删除只作用明确范围，云端保留/备份处理时限按发布前冻结政策展示；新上传停止。
- 验收：TC-DAT-05，详见[对应验收文件](../ac/05-账号同步与数据管理.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。
