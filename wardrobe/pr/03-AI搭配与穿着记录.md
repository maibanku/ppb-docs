# AI 组装、局部替换与穿着反馈

版本：v1.2 · 日期：2026-10-27 · 状态：待设计/技术评审，未代表实现。

[返回需求目录](./README.md) · [对应验收用例](../ac/03-AI搭配与穿着记录.md) · [总 PRD](../PRD.md)

## 范围与来源

W03–W04；FR-04、FR-05、FR-06、FR-13；AC-04、AC-05、AC-09、AC-10、AC-15。

P0 组合与记录；P1 真人试穿；P2 真实三维。

## 目标流程

已确认衣橱 → 可穿性过滤 → 生成一套 → 单品替换 → 保存搭配/就穿这套 → 自愿反馈。

## 数据和依赖

Outfit 记录单品 ID、锁定项、场景与生成来源；WearLog 记录稳定 ID、日期时区与快照；反馈区分明确表达和推断。

## 逐项需求

### REQ-OUT-01 真实单品与归属校验

- 规则：仅使用当前用户已确认、可穿且存在的 ID；模型输出须校验。衣物不足说明缺项，允许保存不完整组合。
- 场景与输入：准备其他用户 ID、已删除 ID、在洗 ID 和缺鞋衣橱。
- 操作与异常边界：注入包含无效 ID 的模型结果；使用缺鞋衣橱生成。
- 输出约束：无效对象不能进入结果或泄露；缺项明确，不编造已有鞋。
- 验收：TC-OUT-01，详见[对应验收文件](../ac/03-AI搭配与穿着记录.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。

### REQ-OUT-02 锁定和单品替换

- 规则：点选单品进行替换；显式锁定项保持不变，冲突说明原因，不自动解除锁定。
- 场景与输入：锁定裤子与鞋的搭配。
- 操作与异常边界：分别手动和 AI 替换外套；再请求与锁定项冲突的组合。
- 输出约束：裤鞋 ID 不变；冲突提示用户调整，原组合仍可恢复。
- 验收：TC-OUT-02，详见[对应验收文件](../ac/03-AI搭配与穿着记录.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。

### REQ-OUT-03 离线与场景

- 规则：无网络使用规则搭配，明确来源；天气或定位不可用时允许手选城市/温度/场景。
- 场景与输入：无网并拒绝定位。
- 操作与异常边界：选择通勤场景发起组合；切回联网但不授权图片上传。
- 输出约束：基础组合可用，不假称云端推理；无静默上传，定位拒绝不阻断。
- 验收：TC-OUT-03，详见[对应验收文件](../ac/03-AI搭配与穿着记录.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。

### REQ-OUT-04 收藏、穿着和反馈

- 规则：保存搭配不计穿着；同一确认动作重复请求只产生一条记录；主动新增另一日记录可独立计数；撤销恢复统计。
- 场景与输入：已保存一套搭配。
- 操作与异常边界：保存两次，点击就穿这套并重发相同操作，新增次日记录，撤销次日记录。
- 输出约束：收藏不增穿着；幂等操作仅一条；次日记录可新增；撤销后回到一条。
- 验收：TC-OUT-04，详见[对应验收文件](../ac/03-AI搭配与穿着记录.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。

### REQ-OUT-05 预览与后续能力

- 规则：P1 真人图有生成标识，不承诺尺寸；预览失败不阻断组合保存。P2 才验证可旋转模型；未启用时明确不适用。
- 场景与输入：已启用预览功能的测试版本。
- 操作与异常边界：生成预览并模拟超时，保存原搭配；低性能模式查看。
- 输出约束：生成标识存在；失败保留组合；静态降级可用；不显示未实现的三维交互。
- 验收：TC-OUT-05，详见[对应验收文件](../ac/03-AI搭配与穿着记录.md)。
- 实现状态：待开发；负责人和排期在开发启动时填写。

### REQ-OUT-06 按选中品类随机与显式锁定

- 优先级：P0；实现状态：待开发。
- 规则：selected_category 表示本次随机的目标品类，不代表锁住该单品。选择外套后随机只替换外套，其他单品 ID 不变；无部位选中时随机整套。显式 locked_item_ids 独立，选中品类当前单品已锁定则提示解除或改选，不自动解锁。排除当前同款 ID、在洗等不可穿项，候选不足不改原组合；支持一次撤销。
- 场景：外套有两件可穿、一件在洗；裤子锁定。
- 输出：有选中时只改该品类；撤销恢复上一组合；锁定时不变化且提示；无替代项明确说明；无选中时整套随机仍保留锁定裤子；随机不自动收藏/记录穿着。
- 验收：[TC-OUT-06](../ac/03-AI搭配与穿着记录.md)。
