# 衣序 · Pen 原型设计简要说明

更新：2026-10-26。用途：供后续创建 `.pen` 原型参考；本文描述当前需求中的设计布局，不表示页面已经开发。暂不创建原型文件。

依据：[总 PRD](../PRD.md) · [具体需求点](../pr/README.md) · [验收标准](../ac/README.md)。

## 1. 风格与布局原则

- 极简、少按钮、容易上手；白/浅灰背景，黑色主按钮，少量蓝色表示选中。
- 参考 WOO 的立体人物展示方向，做原创布局，不精确复刻未经核实的竞品页面。
- App 底部为“穿搭、衣柜、我的”三个入口，每页最多一个高强调主操作。
- 穿搭形象居中，人物侧边放部位图标，下方操作区展示当前单品；没有人物形象时使用二维单品拼搭。
- 登录、日历、同步、设置从“我的”进入；基础衣橱不强制登录。
- 原型中的三维仅作为后续能力示意，单独标注；MVP 静态图不显示旋转提示。

## 2. App 页面

| 建议画板名 | 页面布局 | 功能和主操作 |
| --- | --- | --- |
| App/01-穿搭 | 中央人物或二维拼搭；人物旁部位浮动图标；底部三项操作区及胶囊导航 | 查看单品、随机换搭、拍照分析；点击部位选择替换 |
| App/02-衣橱 | 标题＋右上角添加；分类横栏；两列单品网格；底部三项导航 | 查看、筛选、添加；类别显示全部/上衣/裤子/鞋/包，外套、裙装等可横向查看；状态标记在洗/收纳 |
| App/03-换一件 | 顶部返回；中部保留当前组合；底部面板展示类别和候选单品 | 点击替换，其他锁定项保持；主按钮“保存搭配” |
| App/04-照片拆分 | 原图预览；下方拆分单品网格，每项含勾选和类别 | 修正抠图、改类别、取消误识别；遮挡项标“待确认”；主按钮“确认入库” |
| App/05-单品详情 | 大图；名称、类别、颜色、可穿状态 | 编辑保存；删除放更多菜单；保留来源原图 |
| App/06-搭配与记录 | 搭配图、单品清单；日期和自愿反馈 | “就穿这套”记录实际穿着；保存收藏不增加穿着次数；日历从二级入口查看 |
| App/07-我的 | 简短列表：本地数据、云端增强、同步、账号、导出 | 默认本地；按需授权云端；登录与全量同步分开，不反复弹窗 |

首次进入空衣橱时突出“添加第一件衣服”，不要求先创建人物或录入完整衣柜。添加入口用底部选择面板提供拍照/相册，避免增加常驻按钮。

## 3. Web 页面

| 建议画板名 | 页面布局 | 功能和主操作 |
| --- | --- | --- |
| Web/01-衣物整理 | 简短顶栏；左侧原图约 35%，右侧候选约 65% | 单图拆分、改类、勾选；主按钮“确认入库”；次要操作“调整拆分” |
| Web/02-衣橱与组装 | 左侧分类；中间单品网格；右侧已选组合 | 多选整理、锁定单品、AI 组装；编辑和组装分状态呈现各自主操作 |
| Admin/01-任务管理 | 独立后台入口；左侧精简导航；中间任务表；右侧详情抽屉 | 查看状态、模型、耗时和成本；失败重试；默认不显示私人原图 |
| Admin/02-配置管理 | 模型/提示词版本列表与详情 | 配置版本、灰度与回退；操作权限与审计按需求文档执行 |

个人整理端与运营后台分开画板、分开权限。Web 通过授权同步或导入文件包获取数据，不暗示自动读取手机本地衣橱。一周计划与高级批量整理属于后续版本，不占首版主界面。

## 4. 配色与组件变量（建议值）

以下为本次原型建议，不改变功能需求；使用统一变量，后续可集中调整。

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| bg/page | #FFFFFF | 页面背景 |
| bg/surface | #F5F5F7 | 单品卡片、底部面板 |
| text/primary | #18181B | 标题、正文 |
| text/secondary | #62626B | 次要说明 |
| border/default | #E4E4E7 | 卡片边界、分割线 |
| action/primary | #18181B | 主按钮底色，文字用白色 |
| accent/selected | #2457FF | 选中项、当前导航、细描边 |
| accent/subtle | #EEF2FF | 选中项浅底 |
| status/success | #166534 | 已保存等状态文字 |
| status/warning | #92400E | 待确认状态文字，可配 #FFFBEB 浅底 |
| status/error | #B91C1C | 错误与删除提示 |

状态同时配文字/图标，不只依赖颜色。正式设计需检查文字与背景对比度。

- 字体：系统无衬线中文；页面标题 24、分区标题 18、正文 16、辅助说明 13–14。
- 间距：8 点体系；手机左右留白 20，卡片间距 12，区块间距 24。
- 圆角：卡片 16、底部面板 24、主按钮胶囊形；少阴影，不使用大面积渐变。
- 按钮高度建议 48；其他点击区域至少 44×44 逻辑单位。
- 图标用统一线性风格，导航搭配文字；衣物图保持背景、留白和尺度一致。

## 5. 原型尺寸、状态与连线

建议 App 基准画板 390×844，桌面 1440×1000；尺寸为设计起点，需验证小屏、文字放大与安全区域，不做固定高度裁切。

优先连通两条主流程：

1. 衣橱 → 添加照片 → 拆分候选 → 确认入库 → 衣橱。
2. 穿搭 → AI 搭一套 → 点击单品 → 换一件 → 保存搭配 → 就穿这套。

补充少量状态画板：空衣橱、处理中、拆分待确认、失败重试、离线手动搭配、云端授权、同步冲突。仅本地模式提示“本机保存”；云端任务显示真实进度/状态，失败保留当前数据。

## 6. 2026-10-27 穿搭首页调整（优先于旧布局）

- 最底部采用参考图中的圆角胶囊分段导航，顺序为“穿搭、衣柜、我的”，图标加短文字；选中项用明显底色，非选中保持高对比。参考布局形式，不复制品牌。
- 人物一侧竖排浮动部位图标：外套/上衣、下装、鞋、包和配饰。点击展开该类别的单品底部面板；再点单品替换并可锁定，保持其他锁定项。屏幕较小时图标不遮挡人物核心与操作区。
- 导航上方为三项操作：左侧九宫格“当前单品”，展开侧边/底部网格并显示真实衣物缩略图；中间显著卡片“随机换搭”，只组合衣柜内已确认可穿单品，保留锁定项；右侧相机加星光图标“拍照分析”，进入相机或选择相册。图标有短文字和读屏标签。
- 随机换搭不等于保存或实际穿着；提供撤销，衣物不足时提示补充或允许部分组合。离线使用规则搭配，云端推荐仅在授权后调用。
- 拍照分析流程：按需申请相机权限 → 拍照/选图 → 用户确认照片 → 本地识别或明确授权云端处理 → 展示上衣、裤子、鞋、包等候选 → 用户纠错、勾选 → 确认入库。拒绝权限可选相册；失败可手动裁切。遮挡项标待确认，补全内容标明 AI 生成。
- “我的”承载游客状态、登录、穿搭记录、同步、数据导出和设置；登录不自动开启同步。访客可使用本地基本功能。
- 原型补充：穿搭默认、部位选择、当前单品网格、随机结果/撤销、相机授权、识别待确认、衣柜、我的。画板用安全区布局，按钮触达面积至少 44×44，核心信息不依赖颜色或长按。

后续原型文件建议命名 `wardrobe.pen`，放在本目录；按 App、Web、Admin、Components 分组。优先复用导航、主按钮、单品卡片、候选卡片和底部面板组件。原型旁标注关联需求编号，完成后按验收目录检查布局和操作含义。
