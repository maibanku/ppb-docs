# 衣序 · Pen 原型设计说明

版本 v1.2 · 2026-10-27。供后续创建 wardrobe.pen；当前交付为 UI 功能说明，不代表软件或三维能力已实现。

[PRD](../PRD.md) · [需求](../pr/README.md) · [验收](../ac/README.md)。

## 1. 最新设计基线

整体白色、深色文字、浅色透明玻璃控件、少量蓝色强调。参考用户提供的胶囊切换样式，底部顺序固定“穿搭、衣柜、我的”。图标为主，关键入口配短标签和读屏名称；不使用大面积黑底或黑色主按钮。

底部胶囊建议高 48–52 逻辑单位，不含安全区；触达区域至少 44×44。减少透明度时使用浅色实底，玻璃效果不能降低文字可读性。

## 3. 品类选择与随机

右侧外套、上衣、下装、鞋、包图标选择 selected_category；左侧显示对应当前物品。选择外套后仅随机外套，其余单品不变；无选中时整套随机。选中状态不代表单品锁定，锁定需独立操作和不同图标。目标已锁定时提示，不能自动解锁；没有替代品提示并保留原组合。提供撤销，随机不自动收藏或计穿着。

替换页类别与选中品类一致，外套和上衣不混用标签；保存回首页保留部位选择。单品网格展示真正引用的衣物，不用生成图片伪造衣柜资产。

## 4. 拍照与拆分

进入相机按需申请权限；可选相册。拍照后只在既有授权范围内分析，云端上传需明确授权。检测框可在拍照后显示，实时识别非首版必需。

状态：取景 → 拍摄完成 → 分析中 → 候选待确认 → 可入库 → 成功/失败。无结果、处理中或没有确认勾选项时入库按钮禁用。左侧预览显示本次候选数量，点击检查类别与遮挡情况。待确认项默认不选，用户明确处理后才能选择；补全图标明生成并保留原图。

右侧仅提交当前已确认勾选项，可部分入库；连续点击不重复。重拍不覆盖未保存草稿，先给保留/放弃选择，新照片使用新候选。失败保留照片并支持手动裁切；入库后给数量反馈及去衣柜入口。

## 5. 衣柜与我的

衣柜分类：全部、上衣、外套、裤子、鞋、包；更多类别（裙装、配饰、其他）横向滚动。搜索与分类叠加，数量反映筛选结果；Tab 切换回来保留分类、位置。在洗仍可查看，新推荐不使用。

我的展示穿搭记录、我的收藏、云端增强、数据同步、导出与备份、设置。游客不阻断基础使用；登录不自动开启同步。增强与同步分别显示真实状态，设置行和齿轮共用一个页面。

## 6. 视觉变量与组件

| 变量 | 建议值 | 用途 |
| --- | --- | --- |
| bg/page | #FFFFFF | 页面背景 |
| bg/card | #F5F5F7 | 衣物卡片 |
| glass/surface | 白色约 75% 不透明度 | 玻璃面板，模糊与实底按设备降级 |
| text/primary | #18181B | 正文标题 |
| text/secondary | #62626B | 辅助说明 |
| border | #E4E4E7 | 边界 |
| accent | #2457FF | 选中和主动作文字 |
| accent/surface | #EEF2FF | 浅蓝按钮/选中底色 |
| warning | #92400E / #FFFBEB | 待确认文字/底色 |
| error | #B91C1C | 错误提示 |

统一线性图标；页面标题 24、正文 16、辅助文字 13–14；8 点间距体系，左右 20，卡片间距 12，区块 24。卡片圆角 16，面板 24，主动作高度约 48。单品图统一尺度和留白；玻璃材质要轻，不能让图片/文字混在背景中。

## 7. 原型流程与边界

画板建议手机 390×844，Web 1440×1000，验证小屏/字体放大/安全区。App、Web、Admin、Components 分组；复用胶囊导航、部位栏、玻璃按钮、单品卡、相机操作栏。

优先连线：选部位 → 点左缩略图 → 同类替换 → 保存；选部位 → 随机 → 撤销；AI拍照 → 识别 → 单品确认 → 入库；衣柜分类 → 搜索 → 详情；我的 → 同步设置。

补充空状态、权限拒绝、无替代品、离线、失败、待确认、同步冲突。MVP 没有三维资产时使用二维/静态图，不显示虚假旋转。人像非强制。

Web 个人端保留原图与候选并排的整理模式，运营后台独立权限与任务/模型配置；本轮视觉调整不新增社区、电商、周计划或实时三维能力。概念图尚未复制到仓库。
