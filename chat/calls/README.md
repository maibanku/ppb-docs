设计默认：本地媒体基础设施、真实服务联调；普通通话不自动录制。发起时可以申请录制并明确告知参会者，获得确认后录制；后台有记录查看及获授权录音回放。文字转写为第二阶段，不把“录音存在”与“已转写”混为一谈。
