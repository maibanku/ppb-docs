# 认证与应用接入

[需求基线](../PRD.md)

## 1. 账号与身份（IAM-01/02）

一个全局用户可有多种登录标识与外部身份。密码凭证独立存储，禁止明文或可逆密码存储。邮箱/手机号变更要求重新确权，找回流程不得泄露账号存在性。

外部身份使用可信 issuer 与 sub 识别；相同邮箱不得自动合并账号。账号绑定要求验证已登录主体或旧账号控制权；人工关联须授权、复核和审计。

自助注册默认不授予受限应用访问。禁止首次登录自动创建业务管理员或设置 is_super。统一账号锁定、停用、注销与业务离职含义分别定义。

## 2. 应用与客户端（IAM-03）

应用代表业务产品，客户端代表 Web、iOS、后台等具体接入端。每个客户端独立配置 client_id、精确回调地址、允许流程、scope 与退出回调。

公开客户端不保存 client_secret；机密客户端密钥只保存在后端。开发、测试、生产配置隔离，禁止生产通配回调或任意 return_to。

上游 Google 等登录由 federation 模块处理；向下游应用提供授权由 oauthserver 处理，两者接口与凭证隔离。

## 3. 业务准入（IAM-04）

认证成功后检查应用分配，再由业务检查本地账号状态、tenant、成员关系或管理员资格。普通成员与管理员可映射到同一个 IAM 人员主体，但业务角色分开授予。

认证组织不是业务工作空间，app_key 不是 tenant。任何组织切换均服务端验证成员关系；客户端传入 tenant 不作为可信授权依据。

## 4. 会话和退出（IAM-06/09）

区分 IAM 会话、授权 grant、刷新凭证与业务会话。账户中心展示设备摘要和最近活动，支持撤销指定/其他会话。

当前应用退出撤销当前业务会话，并按客户端策略撤销对应授权；全局退出结束目标 IAM 会话及关联授权，通知应用撤销关联会话。是否包含其他设备通过独立入口明确选择。

全局停用撤销该用户全部会话和授权。单业务组织停用只撤销该业务范围。已有 WS 连接也须收到断连或重新鉴权处理。

密码重置、MFA 重置等高风险操作须定义再认证和会话撤销范围。MFA 恢复码只展示一次，服务端存摘要，恢复使用同样留审计。
