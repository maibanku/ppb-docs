# 验收总则与发布门槛

## G1 协议与凭证

授权码重放、错 client/redirect_uri/verifier、state/nonce 不匹配或过期均拒绝；签名、issuer、audience、过期与算法校验覆盖负例；UserInfo subject 一致；刷新并发和旧凭证重放结果符合契约；密钥正常/紧急轮换可验证。ID Token 不被业务 API 当作 Access Token 接受。

## G2 身份与授权

未分配应用拒绝；普通成员登录管理端拒绝；管理员绑定独立审核；tenant/app 混淆、跨组织访问和空主体直连均拒绝。同邮箱不自动合并，pairwise subject 不误绑定。旧用户主键与数据归属不变。

## G3 会话与退出

当前应用、全局、其他设备撤销范围准确；账号停用、密码/MFA 重置按策略撤销。验证缓存、已连接 WS、重试、乱序、重复事件及故障恢复。实际传播时延不超过 P0 固定值；未固定指标或未验证不能上线相应功能。

高权限认证/会话依赖失败拒绝；现有无 sid 或查询失败放行路径须显式退役或限制，不能无说明继承。

## G4 前端与部署

门户/后台独立构建，未登录回跳和无业务资格无循环；错误可恢复；多标签并行事务互不覆盖。Cookie/CSRF/Origin、回调允许列表、开放重定向、凭证日志泄露检查通过。原生公开客户端不含 secret。退出未完成不得显示全局成功。

## G5 迁移与恢复

新旧账号、重复与删除身份、并发迁移/改密、切换后停用、失败重试与对账均有记录。迁移批次有唯一凭证权威。备份恢复和回退不能复活已撤销会话或旧密码。

## 发布规则

P1 测试闭环必须通过 G1/G4；P2 生产管理端试点通过 G1–G5 适用项，MFA 与高权限策略完成；P3 每个新增应用独立验证 G2/G3/G5。缺失配置时限、证据或责任人均阻塞对应阶段。性能/可用性/撤权目标在 P0 确定数值，再用压力与故障测试证明，不能通过文档检查替代。

验收证据必须脱敏，不保存密码、完整 token、授权码或恢复码。
