# 字段命名调整

> v0.3 → v0.4，目标态设计字段映射，不是存量 ALTER 脚本。

所有列名匹配 `[a-z][a-z0-9]*(?:_[a-z0-9]+)+`。只调整数据库列，OIDC 标准 JSON 字段 `sub/iss/aud/nonce` 等保持标准，不受此约束。

沿用 ppb-base 主键/业务键、时间、软删、逻辑关联和 KV 风格；`name/status/code` 等单词列使用语义前缀。表名没有被要求至少两个单词，保留现有 `user` 表名。
