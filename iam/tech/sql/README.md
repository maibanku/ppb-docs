# SQL入口

[完整DDL与示例种子](schema.sql) · [字段字典](../字段字典.md) · [字段命名调整](../字段命名调整.md) · [数据模型](../数据模型.md)

版本v0.4；MySQL 8.0.16+，InnoDB。共58表，ppb_iam 34、ppb_im 15、ppb_camera 6、ppb_wardrobe 3。schema.sql是单一物理定义；不存在另一份同版本分散DDL。

执行顺序：在隔离空库评审schema.sql；文件按库创建表后插入应用/相机菜单角色示例。不创建用户、默认密码或超管。应用主键使用雪花发号，小ID仅作为本文件新库示例保留区。创建首个超管用受控命令。

这不是存量升级脚本。旧ppb_user、已有ppb_im/camera表不能直接覆盖；迁移另按[计划](../迁移计划.md)回填切换。数据库账号按服务限制库权限，跨服务不做JOIN；逻辑引用由服务验证。

所有列至少双单词snake_case，通用时间/软删列沿用ppb-base，实体专属ID和业务键。OIDC标准响应字段保持标准名。

已验证范围与未验证限制见[记录](../../eval/SQL设计验证记录.md)。没有MySQL实例执行结果，不能把静态/兼容检查当作生产迁移验收。
