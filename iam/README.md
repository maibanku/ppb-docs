# PPB IAM · 文档导航

PPB IAM 是自研 Go 统一身份认证中心。参考 MaxKey 的产品能力边界，不接入或部署 MaxKey。当前采用 ppb-base 同仓独立服务 `server-iam`，独立库、独立构建部署；未来可提取为独立仓库 `ppb-iam`。两种组织方式不改变对外认证契约。
