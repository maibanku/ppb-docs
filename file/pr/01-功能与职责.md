# 功能细则
|需求|行为|主要错误/恢复|
|---|---|---|
|F-01 工作台|仅列file_console个人资源；上传队列、详情、下载、重命名、回收站、用量；视频处理状态与发布状态分开|业务附件跳回原业务，不开放全平台“我的上传”直读|
|F-02 应用接入|管理员配置应用、可信client、政策、存储路由、容量池；server-file验证audience/scope及应用映射|停用应用拒绝新写；存量治理与授权访问按明确政策执行|
|F-03 文件身份|一上传一逻辑文件，内容不可变；同内容允许多个逻辑资源；批量元数据最多100键|非授权/不存在统一不可用；新内容上传新键|
|F-04 上传|BFF申请受限会话；上传分片、ListParts恢复、完成、查询、取消；完成响应丢失重试返回同产物|过期可重新申请；已完成取消返回409；处理中返回202|
|F-05 绑定|业务先准备引用，业务库映射+outbox提交，再提交引用；解绑带递增版本|失联prepared冻结清理，通知业务核对；不靠超时盲删|
|F-06 访问|业务检查权限后申请短期下载/预览/播放凭证；批量也是逐对象校验|下架、回收、应用隔离统一拒绝；签名泄漏有效期内可用是已知边界|
|F-07 生命周期|准备、有效、回收保护引用均阻止GC；个人回收30天；purge释放一次|恢复清除purge期限；业务附件由业务恢复|
|F-08 视频|真实探测、封面、MP4及P1 HLS；处理异步，取消不使已使用产物失效|失败重试同任务或新版本；结果就绪不自动发布|
|F-09 治理|元数据检索、异常、任务、配额、后端测试、下架恢复、审计|所有管理写入审计，内容读取单独break-glass权限|
|F-10 迁移|旧键保留，旧API适配，持有计数重建，双路比对|未完成对账禁止切新GC|

个人文件夹、标签和收藏若实施，应归file_console业务BFF元数据，不放blob。媒体通用尺寸、时长、编码归媒体库，作品文案、衣服品类、聊天会话归各业务库。扩展元数据JSON仅白名单、大小限制和schema验证，不替代常用检索字段。
